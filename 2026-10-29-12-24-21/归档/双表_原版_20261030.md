# 瀚森投喂日记 · 双表：爆款池 + 日常池

拆成两张**互不重合**的表：**爆款池 46 条**（主力涨粉）+ **日常池 124 条**（保发布量），合计 170 条 = 日记抽取 167 条（含 B45 由日常池升级、B46 为看房场景新补）+ 10-30 补录 2 条（B43、B44），无一条重复。

## 怎么配合用

| | 爆款池 | 日常池 |
|---|---|---|
| 作用 | 拉新、涨粉、冲播放 | 维持更新、养账号权重、留老粉 |
| 挑法 | 每 4 条里插 1 条，宁可少也要精 | 其余 3 条，稳定输出 |
| 标准 | 有强反差 / 强共鸣 / 强情绪 | 可爱、清楚、安全、不踩雷 |
| 失败代价 | 高（要重做） | 低（发出去就行） |

## 发布节奏（每 2–3 天一条）

```
4 条一个循环：  爆款 → 日常 → 日常 → 日常
间隔：         2 天、3 天交替，均值 2.5 天
一个循环约：    9–11 天
一个月约：      11–13 条（其中爆款 3 条）
```

具体日期见《发布排期表》。

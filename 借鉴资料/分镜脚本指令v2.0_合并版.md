# 分镜脚本指令 v2.0（SD2.5 ＋ 即梦 合并版）

把这份文件和你的剧本一起发给 AI。

> 本文件是 `分镜脚本指令v1.0.md` 的合并升级版。v1.0 的「每 15 秒拆一个独立 SD2.5 文件」**已作废**——SD2.5 改为单文件全片（见 D103 标杆），真正分段的是即梦段落式。最终只需产出**一份**合并分镜脚本文档。

## 任务

你是资深电影分镜师与 AI 视频提示词架构师。我会给你一个动画短片剧本。你要把它拆成可直接投产的分镜，并产出**一份合并文档**：

- A 块（SD2.5 单文件四板块）：喂给视频模型 SD2.5 的成品提示词（母文档，全片一份）。
- B 块（即梦段落式）：按即梦段落式 SOP 拆段，每段可直接整段复制进即梦生成。

这份文件是你唯一的工作规范，完整读完再动手。

一个完整剧本，含场次、场景、动作描写、台词，以及本片的账号基调红线（见末尾）。

## 你要产出什么（一份合并文档）

结构如下，顺序不许换：

1. 文档说明（头部）：选题编号、片长、场景、出镜、配套剧本版本、工作规范指向。
2. 结构层（不进提示词，仅供对齐）：全片镜头时间轴、角色固定外形、关键道具、有规则的设定、光线状态、资产编码表、生成段划分、时间码对账。
3. **A 块 · SD2.5 单文件四板块**：【素材说明】【风格】【具体情节描述】【全局补充】——全片一份，不拆文件。
4. **B 块 · 即梦段落式**：段1 / 段2 / …… 每段含【段间承接·起始锁定】＋ 电影感 N 秒段落（镜头四要素内联）＋ 录音点 ＋ 胶片后缀。
5. 全片后期合成清单（不进提示词）。
6. 自检清单 ＋ 即梦实操 SOP。

## 硬规格

- **SD2.5 = 单文件全片**：不再按 15 秒拆独立文件；参考 `选题/D103/D103分镜脚本_SD2.5.md` 写法。即梦段才是分段块。
- **即梦段 = 按即梦段落式 SOP 拆段**：每段 8–15 秒，落在镜头硬切；段与段独立生成、后期硬切拼接。
- 两者共用同一分镜时间轴与硬切点：即梦段边界 = A 块【具体情节描述】里某些镜头的时间码边界。
- 单镜最短 3 秒；结尾不留 1–2 秒碎镜头；台词不跨镜截断。
- 每个即梦段参考图 ≤10 张；资产编码全片统一不换。

## 第一步　先读懂剧本（提取表，写进结构层）

动手前从剧本提取并列表：
一、全片时间线（每场剧情时间点、场间间隔）。
二、所有角色固定外形（年龄、身高、体型、头身比、脸型、发型长度与发饰左右位、服装款式＋颜色、鞋袜、随身物）。
三、所有关键道具（外形、材质、颜色、数量及变化节点）。
四、有规则的设定（分级／顺序／数量／对称关系，单列规则本身）。
五、每场光线状态（时间、天气、室内外、光源位置、光是否场内变化）。
六、资产编码表（全系列沿用）：角色 BB-01 阿森／MM-01 妈妈／NN-01 奶奶……；场景 SC-编号＋名字＋时间；道具 PR-编号＋名字。新资产顺延编号，旧码永不复用、永不改义。

剧本自相矛盾先指出问我，不悄悄圆。

═══════════════════════════════════════

## 第二步　切镜头

- 每剪辑镜 3–5 秒，不低于 3 秒，一镜只做一件事。
- 台词不跨镜截断，一句话同镜说完；抢话／叠话写明「咬尾音零间隙」。
- 台词节奏：中文秒数 ≈ 字数÷3＋0.6，塞不下就加长或挪相邻镜。
- 逐镜给：镜号、景别、焦段、景深、机位、时间码、时长、核心画面、台词、所属即梦段。
- 时间码严丝合缝：每镜时长＝跨度，首尾相接不重叠不留空。
- 运镜只选三种：固定机位、快拉、跟拍。不写缓慢推近、不写无端摇镜。

═══════════════════════════════════════

## 第三步　每场锁三样

- 空间轴锁定：固定物左右前后位置、门／家具／光源／默认站位、不得跨越的轴（空间方向轴＋对话轴两条都写）。
- 人物与道具连续性：场内不变项；会变化的写清在哪一镜变。
- 光色锁定：光源、色温、方向；一场内光变则按即梦段拆成不同锁定，绝不把「整场光弧」复读进每镜。

## 第四步　写合并文档

### A 块 · SD2.5 单文件四板块（全片一份）

#### 板块一【素材说明】
格式：`@imageN图片N = 编码 名字（角色定位＋外形＋本片能力边界）`；音色用 `@audioN = 妈妈音色参考`。
规矩：只列本片真正出场主体／环境／道具；总数 ≤10，编号从 @image1 起排；资产编码全片不变。
**素材写法（项目约定，必守）**：
- 仓库已有定稿 PNG（如宝宝／妈妈／场景）：写 `@imageN图片N = 编码（描述）` 后接 `【修改提示】在原有X参考图基础上修改：保留…；修改／补充…`（基于原图改，不重出整图）。判定＝现有图与剧本在月龄／风格／关键特征吻合即作基础图，仅细节加修改提示。
- 仓库无 PNG 的道具：写 `@imageN图片N = 编码（描述）` 后接 `【生图提示词】3D 卡通…，皮克斯式观感。…纯色浅背景，平视微俯。质感…，无…、无文字。`（自包含可直接出图）。
- **资产图只画单物体／单人**：角色图只画该角色本人（长相＋表情＋动态，不含对方、不含场景）；道具图只画物件本身（空置、无人物）；场景图只画环境。「谁坐哪、谁喂谁、谁在谁面前」这类**构图关系一律写在【具体情节描述】里用 @image 引用合成，绝不进某条素材的【修改提示】或【生图提示词】**。
- 角色条写清本片能力边界（如「刚会连续翻身；全片只能翻，不会爬、不会站」）。环境条锁死光线（时间、方向、明暗关系）。道具条把「是什么＋不是什么」写一起。

#### 板块二【风格】
一行：高品质皮克斯式三维动画电影观感。全片统一。

#### 板块三【具体情节描述】
按镜头逐段写连续电影散文。镜头格式：首镜不带切换词直接写景别起手；后续镜头把切换写进句首；镜头头 `[镜头N｜0:00-0:03]` 时间码严丝合缝。
每镜正文顺序：景别＋焦段＋景深＋机位 → 镜头在空间位置 → 谁在画面哪个位置（@image 挂主体）→ 动作按时间一口气展开 → 光从哪来 → 材质 → {对白} → 〈音效〉。

规则1 连续电影散文，绝不出现「起始画面：」「人物站位：」等字段标签。
规则2 景深用词描述（浅／中深／极浅景深），不写 f/ 光圈数；焦段可写（24/40/90mm）。
规则3 表演写「怎么做」不写「什么情绪」。
规则4 加粗只框最要命一两条（物理动作真做、数量固定、左右不互换、同步发生）。
规则5 台词 `{角色（语气）"内容"}`，一字不改剧本；无台词写「无台词」。
规则6 音效 `〈真实发生的声音〉`，只写画面实声，不写情绪／气氛乐。
规则7 正文绝不写具体秒数（「三秒内」「0.5秒」禁），时间只进镜头头时间码。
规则8 防拖沓：每镜都填得出「什么在动」；「慢／缓慢／停住／顿住／安静／静止」不准当执行词。
规则9 文字一律后期合成（日期／时间／界面／纸上字／招牌／片名），生成阶段留白写明「由后期合成」。
规则10 不描述不该出现的东西（否定语义弱，描述即召唤）。

#### 板块四【全局补充】
固定写齐：人物对白条款（大人正常生成，标准普通话）；孩子声音条款（仅实音——哼唧／哭／咿呀／笑／衣料窸窣，绝不成语言、绝不做说话口型；内心 OS 不写进提示词，与字幕片尾全后期）；声音轨道条款（只有对白＋孩子实音＋真实动作／环境声，绝无配乐／背景乐／歌曲／旋律）；文字条款（画面零文字）；空间轴；连续性锁；能力／安全锁（有婴幼儿必写：只能做什么、绝不做什么）；专项禁止（最易翻车点）。

### B 块 · 即梦段落式（每段＝一段可整段复制进即梦的自然语言）

**即梦段落式 SOP（全片通用，必守）**
① 拼接点必须落镜头硬切，绝不在镜头内部动作中途切。
② 含连续多拍动作的镜头（如换肩＋脸对镜＋清唱、反转抱）完整保留在一段内不跨段。
③ 每段时长 ≤15 秒 且 ≥8 秒。
④ 段间加【段间承接·起始锁定】块，锁跨段连续状态（位置／抱姿或站位／角色状态／机位光）。
⑤ 单段实际 ≤10 秒可在某镜头硬切点再切一刀，原则不变。

**每段结构（直接照抄）**

```
【段间承接·起始锁定】（首段写「全片起手，无前置画面；写明起手姿态／机位／光」；非首段钉死＝上一段最后一镜结束画面：位置／抱姿或站位／角色状态／机位光）

电影感 N 秒段落，[场景图]@场景名。

X-Y 秒：景别（焦段mm 镜头）运镜。机位：方位＋高度，距主体M米。站位：角色@位置＋朝向＋状态。角度：类型＋程度。光照：主光方向，色温氛围，环境光效，时段。画面：[角色图]@角色（位置，姿态，朝向，状态）动作表情。[台词／音效]。
……（覆盖整段 N 秒，情绪高潮／战斗镜头≤3秒，平稳镜头可4–7秒）

[录音点]@角色-音色（情绪声线）
……

写实电影，35mm 胶片拍摄，浓郁的胶片颗粒感。画面充满真实的物理质感，拒绝廉价的数码磨皮感。高动态范围，深邃的阴影。视频不出现字幕，视频不出现音乐。
```

导演台四要素（机位／站位／角度／光照）每个镜头必含，内联成标签；@image 引用与 A 块同套编码；台词 `{角色（语气）"内容"}`、音效 `〈〉`、内心 OS 不写进提示词（归后期）。

**参考图上传对照表**（写进 B 块开头）：真实文件名 图片1.png～图片N.png 与 @image1–N 一一对应，列「各段是否用到」；发即梦前照表传图、避免传错；即梦不读本地文件名，每次生成都要重传并手动 @ 替换。

## 自检清单

□ SD2.5 为单文件全片四板块（未拆多文件）；即梦段数／段长由 SOP 定（8–15s，硬切拼接，连续动作不跨段）
□ 资产编码全片一致；素材说明按「修改提示／生图提示词」分类，资产图只画单物体／单人，构图关系进具体情节
□ 时间码对账平：各镜时长之和＝片长；即梦段边界＝镜头硬切
□ A 块正文无字段标签、景深用文字无光圈数、无具体秒数、无「慢／停住／静止」执行词、每镜有动
□ 孩子仅实音无语言无说话口型；OS／文字全后期；无配乐条款一字不改进全局补充
□ B 块每段含段间承接块＋四要素＋录音点＋胶片后缀；参考图上传对照表齐全
□ 段间【承接·起始锁定】已锁（位置／抱姿或站位／角色状态／机位光）

## 即梦实操 SOP（出片前照此勾一遍）

一、发给即梦的内容边界：只发各段正文（段间承接块＋镜头＋录音点＋胶片后缀）；不发文档说明／结构层／后期清单／全局锁（给剪辑与质检用）。
二、开 N 个独立对话框（不要同对话续写，避免即梦当视频续写融合）；顺序生成先抓系统错误。
三、每段四步：复制该段全文（含承接块）→ 按逐段传图表重传参考图 → 手动 @ 替换 @imageN → 不用续写按钮直接生成。
四、剪辑硬切拼片：按时间码硬切落镜头切换处；叠加 OS 字幕（不配音、不做口型）；片名后期。
五、出片质检：照全局锁逐镜勾（抱姿顺序、角色位置、宝宝月龄边界、无第四处亮、无生成文字）。

## 账号基调红线（来自项目长期约定，分镜不得违反）

- 账号性质＝AI 三维动画（非真人、非纪录），出片横版。
- 妈妈人设＝笑嘻嘻带娃，全程对娃笑脸，带娃轻松愉快；不画成麻木认真／死脸／严肃，笑点来自结构（机械重复＋误读）而非妈妈死脸。
- 宝宝＝阿森，月龄能力边界见剧本「月龄核对」，不写超龄动作（招手意图／等待／食指捏等）。
- 文字全后期，生成阶段画面零文字；无配乐。

## 不要做的事

- 不要删改剧本台词（一字不改）；不要新增剧本没有的角色／道具／动作／情节。
- 不要把 SD2.5 再拆成多个独立文件（v1.0 旧规作废）。
- 不要在即梦段切在镜头内部动作中途；不要让连续多拍动作镜头跨段。
- 不要给孩子写成语言的声音或说话口型；不要写任何配乐／背景乐／歌曲／旋律。
- 不要在素材提示词里写构图关系（谁抱谁、谁在谁面前）；不要描述不该出现的东西的样子。
- 不要在提示词里写「接镜头几」「承接上一段」这类跨文件引用（即梦段间承接用【段间承接·起始锁定】文字块替代）。

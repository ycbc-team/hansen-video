# 剧本复核 SOP · 四轮清单法

> 用途：剧本定稿后、出分镜前的固定复核流程。四轮各换一个切入角度，逐轮发现、逐轮收口，四轮全过即可进入分镜／交付。
> 来源：2026-11-17 B35《阿森的胜负欲》四轮实战沉淀。
> 配套：与 `剧本生成v1.1_可复制粘贴.md` 一起用——那份管"怎么写"，这份管"写完怎么查"。复核时以 v1.1 为判定依据。

---

## 0. 怎么用（三条原则）

1. **按顺序走，一轮一个角度。** 不要一上来把所有维度混在一起扫——那样既容易漏，也容易把"发现一处报一处"变成无限轮。每轮的切入角度是固定的，扫完即收。
2. **每轮走闭环：发现 → 报用户 → 拍板 → 改 → 针对性核验。** 不确定的、属于风格取舍的（比如某句台词要不要动），列为"待拍板"，不擅自改；硬冲突才默认必改。
3. **四轮全过就收口，不开第五轮。** 复核到第四轮边际收益已经很低，再扫就是纯耗时间。除非中途新增了镜头／台词／角色改动，才从对应轮次回炉。

四轮角度一览：

| 轮次 | 切入角度 | 一句话 |
|---|---|---|
| 一 | 连续性硬冲突 | 前后矛盾、姿势／光线／时间、设定 vs 正文 |
| 二 | 清单式全维度 | 台词／机位／动作／月龄／场景／OS 逐项扫 |
| 三 | 因果链＋元信息 | 因果环环相接、表格数字、闸值、口径 |
| 四 | 人设铁律逐镜落地 | 逐镜查"笑"是否写进正文，不是注释 |

---

## 1. 第一轮 · 连续性硬冲突

**本轮目标**：抓相邻镜头之间的物理断点，以及"设定"和"正文"互相打架的地方。这是最显眼、最该先清的一类问题。

**检查清单**
- **姿势接续**：上一镜末尾把娃摆成什么姿势，下一镜开头就接什么姿势。翻正／俯卧／仰卧／被抱起，逐个对。
- **光线／时间**：场景状态写了"光恒定"就不许正文再让光带移位；写了"时间跳跃"就要有过场字幕兜着，不靠光线变化暗示时间。
- **物件连续性**：道具在谁手里、放在哪，中间有没有凭空转移（隔着明确时间跳跃的可放过）。
- **设定 vs 正文**：场景状态 B、一句话梗概、月龄、机位等元信息，和逐镜正文有没有对不上。
- **说话对象与视线**：台词是冲谁说的，那个人的位置在不在说话者的视线方向里。

**判定口径**：前后两句如果描述的是"连续的下一秒"，姿势／位置／光线必须能对上；对不上就是硬冲突，默认必改。与画面拧着的台词（画面喝了奶却说"奶都不喝"）也归本轮，列为待拍板。

**B35 案例**
- 光带硬冲突：场景状态写「全片光恒定，不随时间变化」，镜 6 正文却写「斜光带从垫子一侧移到另一侧」。改法：保留"光恒定"（它是防生成模型乱变光的约束），删掉移位描写，时间推移交给过场字幕＋台词＋哥哥玩远三样。
- 姿势断点：镜 2「妈妈把他翻正过来」（脸朝上）→ 镜 3「脸还埋在垫子里」（脸朝下）。改法：镜 2 末尾改「妈妈伸手拍了拍他的背」，不动姿势，镜 3 就接上了。
- 待拍板项：台词六「奶都不喝就累得睡着了」和画面"含瓶吸两口"拧着，用户改口为「奶还没喝两口就累的睡着了」。

## 2. 第二轮 · 清单式全维度扫描

**本轮目标**：针对第一轮"发现一处报一处"的缺点，把第一轮没覆盖的维度一次性按清单扫完。**清单是固定的，逐项打勾，不许跳。**

**检查清单**
- **台词跨段一致性**：梗概／正文／对账表／评分表里的台词引用是否同一句，字数统计是否和正文对得上。
- **机位可见性**：每个走位／反打，在对应机位的资产图里看不看得到。主机位拍不到的地方（如玄关在镜头背后），不能让角色从那里出来，改用画外声音＋从可见侧走进画面。朋友／配角站的位置也要在可见范围内。
- **动作数与精确接触**：单镜动作不超过约 5 拍；"抱起→托头→坐沙发→递瓶→含嘴→瞟"这类日常连贯动作可保留，但精确到指尖／瓶嘴的接触不要连拍，拆镜或压拍。
- **月龄逐镜**：逐镜检查每个动作是不是这个月龄做得到的（如 3 个月只能追视、抬头、抓握、吸吮，不蹬腿带身体、不吃脚、不翻身独坐爬）。
- **场景设定与正文细节**：坐／蹲、站在哪一侧、拿没拿东西，设定和正文若同时写了就必须一致。
- **OS 规则**：OS 只写感知（会动／会响／暖），不替孩子认人、不写心思（不写"不能输""要追上他"）。

**判定口径**：清单每项都要有明确结论（过／待改）。这轮最容易出现"上一轮以为改好了其实没接上"的情况——修完一处要回头看它和相邻镜头的接口。

**B35 案例**
- 漏网之鱼：第一轮把镜 2「翻正」改成「扶回趴着的姿势」，自以为修好；第二轮一逐镜对就露馅——娃被摆成趴好、能抬头的样子，不会又自己埋回去。正解改「拍了拍他的背」。
- 机位穿帮：镜 9「对面朋友」位置没锁。查场景资产设定：主机位左侧电视柜、右侧沙发，妈妈抱娃坐沙发在右，"对面"只能是电视柜那侧。改正文和注释为「站在电视柜那一侧的朋友笑着摇头」。
- 清单通过项：台词跨段一致、无单镜超 5 拍、月龄逐镜过、OS 两句皆感知、机位名全在资产设定内。

## 3. 第三轮 · 因果链＋元信息自洽

**本轮目标**：前两轮都在"看镜头"，这一轮跳出镜头本身，查**因果链条通不通**和**元信息（表格数字／闸值／口径）算得对不对**。

**检查清单**
- **因果链**：把每个情节点连成一句话，看是不是环环相接（被夸→抬头→追视→十分钟后还抬→喂奶睡着），有没有哪一步缺了前提或凭空发生。
- **注水闸数字**：按 v1.1 闸值（每 10 秒 ≥0.8 个节拍、相邻节拍 ≤9 秒）实算节拍密度和最长空档，和评分表填的数字对一对。脚本核验见附录。
- **表格数字自洽**：时长对账表各段秒数之和、台词字数合计、镜号总数，和正文逐项对。
- **口径一致**：同一件事在不同地方的说法（如"两口"／"还没喝两口"），口语可接受就不动，但要在心里有数。

**判定口径**：数字填错即使不影响结论（如 8 秒实为 9 秒、仍不扣分），交付物也必须自洽，要改。压闸值的段落标注"后续别再拉长"，提醒后续改动风险。

**B35 案例**
- 注水闸填错：评分表写「最长相邻节拍间隔 8 秒」，实算是 9 秒（节拍点 4／10／15／24／30／35，间隔 6-5-9-6-5）。9 秒压闸值上限、不扣分，但数字要改对，并标注"这段没有余量"。
- 坐／蹲不一：场景状态 B「妈妈坐在垫子边」vs 镜 1「蹲」，统一成"蹲"。
- 因果链全过：夸哥哥→抬头→哥哥跑维持追视→十分钟后还抬→喂奶睡着，环环相接。

## 4. 第四轮 · 人设铁律逐镜落地

**本轮目标**：项目铁律是"妈妈全程笑嘻嘻带娃、不许死脸／严肃"，但要查的是**每镜正文里有没有真的把"笑"锁住**，而不是只在注释或台词标注里写。

**检查清单**
- **逐镜扫妈妈**：把每个有妈妈出镜的镜头正文单独拎出来，看有没有"笑"字。只在台词标注里写"笑着说"不够——喂生成模型的主要是正文，整格无台词的镜头最容易画出一张认真陪练脸。
- **逐镜扫宝宝**：同理，表情／状态是否写进正文（如"眉头挤着、嘴唇抿着"），而不是靠注释补。
- **铁律落地**：笑嘻嘻带娃、不画死脸、笑点来自结构（机械重复＋误读）——逐镜确认没有反向描写。

**判定口径**：角色在画面里、正文却没锁对应状态的，一律补写。纯增补不碰结构，补完做针对性核验即可，不用整份重扫。

**B35 案例**
- 逐镜扫描结果：镜 3–6、8–9 正文都有"笑"；镜 7 妈妈不在画面（贴地近景只拍阿森）无需；唯镜 1、镜 2 妈妈在画面却没锁笑。
- 改法：镜 1「妈妈蹲在垫子边，**笑着**看他使劲……」，镜 2「妈妈**笑着**拍了拍他的背」。两处纯增补，不碰光带／姿势／字数／镜号。

## 5. 贯穿检查项：注释拆台（每轮都顺手扫）

这项不单独占一轮，但每轮改完都要扫一遍，因为它最隐蔽、影响最大。

**规则**：等／期待／故意／较劲／动机／想被夸／嫉妒这类心理词，**只要出现在注释里就是指令**——紧跟否定也挡不住，模型会照前半句画。判定依据是 v1.1 注释第 5 条。

**改法**：把否定式心理句全部换成**纯画面事实**（眉头挤、脸憋红、嘴抿线、脖子绷；睡着那一下只写"眼睛没睁、嘴含瓶嘴、下巴垂下"）。心智／情绪只保留在大人台词里（作为大人的误读），并注明"属于谁、不属于画面里的宝宝"。

**例外（不喂模型，可保留）**：月龄核对表、评分对齐表里的"较劲""想被夸"等词属于交付表格，不进生成提示词，保留无妨。扫的时候要分清"正文／注释"和"交付表格"。

**B35 案例**：注释里「不是心里憋着一股要赢的劲」「不是他心里不服气」「别显出坚持或痛苦」全部清掉，改成纯画面描写；"想被夸奖"只留在朋友那句台词和月龄核对表。

---

## 6. 收口标准

四轮全部走完、每轮发现都处理完，且终检全绿即可收口交付／commit：

- 段秒数逐段等于时间码之差、合计等于总时长
- 镜号连续不跳号
- 台词字数在时长档上限内、OS 在规定句数内
- 注释／正文无拆台心理词、无否定式反例、无生成禁用的静态词（缓慢／静止／定格等）和破折号
- 光恒定、月龄一致、妈妈全程笑嘻嘻
- 注水闸密度达标、数字自洽

**不再开第五轮。** 若收口后又要改镜头／台词／角色，只从受影响的那一轮回炉，不要整份重扫。

## 附录：通用脚本核验模板

每轮改完把下面脚本跑一遍，替换剧本路径即可。脚本只做机械核验，逻辑判断（因果、人设、月龄）仍靠人工。

```python
import re
p = '剧本路径.md'
s = open(p, encoding='utf-8').read()
body = s.split('```')[1]

# 1. 段秒数：每段时间码之差 == 标注秒数，合计 == 总时长
segs = re.findall(r'0:(\d\d) — 0:(\d\d)（(\d+) 秒）', body)
print('秒数:', [int(x[2]) for x in segs], '=', sum(int(x[2]) for x in segs))
for a, b, c in segs:
    assert int(b) - int(a) == int(c), f'秒数不符 {a}-{b} vs {c}'

# 2. 镜号连续
jn = re.findall(r'^镜 (\d+)。', body, re.M)
n = len(jn)
print('镜号连续:', jn == [str(i) for i in range(1, n+1)], '共', n, '镜')

# 3. 台词字数（汉字）与 OS 句数
tl = re.findall(r'（台词[一二三四五六七八九十]+[^）]*）：「([^」]*)」', body)
cnt = [len(re.findall(r'[\u4e00-\u9fff]', t)) for t in tl]
print('台词字数:', cnt, '合计', sum(cnt))
print('OS:', re.findall(r'阿森OS：「([^」]*)」', body))

# 4. 拆台心理词 / 生成禁用静态词 / 破折号
bad = ['较劲','动机','嫉妒','赌气','不服气','要赢','有情绪','想被夸',
       '缓慢','慢慢','缓缓','停住','顿住','静止','安静','定格','凝视','若有所思','——']
hits = [(w, body.count(w)) for w in bad if w in body]
print('残留:', hits if hits else '0 处 ✓')
```

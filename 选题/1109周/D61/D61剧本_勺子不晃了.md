# 勺子不晃了

**一句话梗概**：妈妈吹凉辅食时左右转脸，阿森看着她也晃起脑袋；妈妈把勺子送开、自己不再转脸，小脑袋却还晃了两下。

**本条的场景状态**：上午十点，餐厅保持定稿图的奶油木色暖光、三头奶白球罩吊灯、纵向木餐桌和中央藤编花器，前景不出现岛台。阿森的餐椅贴在餐桌靠客厅的远端，妈妈坐在紧挨餐椅的木椅上，两人侧身相对，相隔一臂以内。妈妈手边的桌面放一只装有温热南瓜泥的米白小碗，浅木小勺从碗里舀起，碗与勺在第一镜就入画。宝宝坐稳在餐椅内，托盘和安全带保持原位，桌面其余位置不新增物件。

**剧本**

0:00 — 0:07（7 秒）　镜 1—2　吹凉一勺

镜 1。餐厅全景机位，中景固定。妈妈坐在阿森身旁，米白小碗放在她手边，浅木小勺舀起一小口南瓜泥；阿森坐在餐椅里，两只手搭在托盘上，眼睛追着勺子走。
妈妈（台词一）：「吹凉了咱们再吃，啊。」
镜 2。切。餐厅全景机位，双人近景。妈妈对着勺面吹气，脸朝左转一下、回正、再朝右转一下，头始终竖直；阿森的眼睛跟着她的脸从左移到右，脚丫在脚踏前轻轻蹬了两下。

（开头七秒要交代碗、勺、两人的距离，以及阿森注意到的到底是什么。碗在妈妈手边，勺子从碗里出来，下一段喂食才不会像凭空出现道具。第一镜把两张椅子和同一张桌子的远端装进画面，不推镜，也不让妈妈隔着整张餐桌探身；她伸手就能碰到托盘，吹勺的脸就在孩子眼前。切到双人近景，是为了让观众同时看见妈妈水平转脸和阿森追视，不能只拍一张嘴吹气，否则下一格的晃头没有看得见的来源。妈妈转的是脸朝向，不是歪着脖子甩头，幅度只需让左右两个方向清楚。此处阿森只追视、蹬脚，不提前晃脑袋；如果在第一勺就开始晃，第二段便失去第一次意外。南瓜泥是温热待吹的食物，勺子始终在妈妈手里，不把冒烫气的食物送入孩子嘴里。两人始终在餐桌远端同侧，背景沿用定稿图的位置关系。）

0:07 — 0:14（7 秒）　镜 3—4　脑袋跟上

镜 3。切。餐厅全景机位，双人近景。妈妈又从碗里舀起一小勺，朝左、朝右各转脸吹一次；阿森先用眼睛追她的脸，随后脑袋也朝左偏一点、朝右摆回来，回正时又轻轻抖了一下。
镜 4。切。餐厅全景机位，阿森近景。勺子还在画面边缘，阿森的身体由餐椅稳稳托住，小脑袋左右晃两下，每次都比妈妈的转脸晚半拍，托盘上的手指跟着一张一合。
妈妈（台词二）：「哎，你的小脑袋也晃起来啦？」
阿森OS：「我也来。」（压在第二下小幅晃头上，只走后期声音。）

（这一段的转折由阿森的脑袋发动，画面要让观众看见他从追视转成小幅跟动。妈妈再次吹勺是重复前一段的可见动作，镜三同框保住输入与反应，不用一个妈妈特写接一个宝宝特写去拼因果。镜四才收近，读清小脑袋回正时那一下不齐整的抖，孩子坐在固定餐椅里，上身不离开靠背，脚也不把椅子蹬动。阿森不是听懂妈妈的指令，也不是在说不要吃；OS只是配在画面外的玩笑，脸上不做说话口型。妈妈的台词是看见新动作后的脱口而出，带着笑说，不要训孩子，也不要把小幅晃头演成猛烈甩头。两次晃头之间有眼睛继续追脸、手指开合，近景每秒仍有动作。最容易做错的是把母子画成左右完全同步的舞蹈，宝宝要晚半拍、幅度小、回正略抖，观众才能读出七个月婴儿的笨拙感，而不是一个会做整套摇头动作的大孩子。）

0:14 — 0:21（7 秒）　镜 5—6　勺子追脸

镜 5。切。餐厅全景机位，双人中景。妈妈把已经吹过的勺子往阿森嘴边送，阿森的脑袋还沿着刚才的幅度向旁边偏，勺子从嘴角旁经过，没有碰到脸；妈妈随即把勺子撤回自己这一侧。
镜 6。切。餐厅全景机位，双人近景。妈妈笑着把勺子放低到阿森胸口以下，再举到他的视线里；阿森看着勺子，小脑袋回正，又朝旁边轻轻摆了一下。
妈妈（台词三）：「我不晃了，你也歇一会儿？」

（这里的笑来自一件很小的错位：妈妈按正常的送勺路线靠近，孩子自己还在晃，嘴的位置刚好移走。镜五一定要让勺子从嘴角旁空过去，既不能撞上脸，也不能让妈妈继续追着晃动的嘴喂，食物没有落到托盘或脸上。她立即撤回勺子，表明她先看见孩子的动作再调整，而不是为了喂进去硬把勺子往前戳。切到镜六以后勺子先降到胸口以下，给孩子一个不被勺子贴脸追逐的空间；妈妈仍坐在一臂以内，笑着重新把勺子举到孩子看得见的位置。阿森的视线从妈妈脸上转回勺子，头回正后又摆一次，这就是本段第二个看得见的笑点。台词只是妈妈逗孩子的猜测，不能让阿森随口令停下，下一格也不能表现为他听懂了。镜头不用俯拍，因为俯拍只见勺与头顶，看不清勺头从嘴边错过，观众也就不知道为什么妈妈撤勺。）

0:21 — 0:28（7 秒）　镜 7—8　妈妈不动

镜 7。切。餐厅全景机位，双人近景。妈妈把勺子留在自己手边，脸正对阿森，不再左右转；阿森盯着她，头先向一侧偏、再往另一侧摆，两只手交替拍一下托盘。
镜 8。切。餐厅全景机位，双人中景。妈妈看着阿森笑，手中的勺子只在碗上方移动；阿森的头回到正中，脚丫又蹬了两下，接着脑袋朝旁边晃出一小截。
阿森OS：「还在晃。」（压在妈妈脸不转、他自己又偏头的动作上，只走后期声音。）

（妈妈已经不提供可供跟着转的脸，阿森却还有一两下小动作，这一段把重复变成新的状态，不需要妈妈追加夸张逗娃动作。镜七把母子脸放在一个画幅内，观众一眼能比较出妈妈的脸朝前、宝宝的头还在左右偏；只给孩子单人特写，会丢掉这条最有趣的对照。妈妈的手与勺子留在自己那一侧，阿森拍托盘、蹬脚，双人画面即便有短暂的眼神交流也不会成为空画面。镜八放宽到中景，是为了交代勺子在碗上方、孩子仍坐稳，下一段的送勺有连续的起点。宝宝每一下偏头都要轻，不要扭身、不让餐椅晃动；这不是能听懂妈妈要求后的摇头答复。OS压在第二次偏头处，不给口型，也不让画面变成孩子和大人隔空对话。妈妈笑着看他，却不急着追着送第二口，照顾动作是先把勺子留在安全距离，再看孩子的头能否回到正中。）

0:28 — 0:36（8 秒）　镜 9—10　勺子不晃

镜 9。切。餐厅全景机位，双人近景。阿森的脑袋回到正中，嘴巴张开；妈妈把一小口已经吹凉的南瓜泥送到他嘴边，他吃进去，妈妈把空勺撤回碗上方。
妈妈（台词四）：「这口终于给你吃上了。」
镜 10。切。餐厅全景机位，双人近景。勺子已经离开阿森嘴边，妈妈的脸朝前、手在碗上方舀起下一口；阿森咽下嘴里的泥，脑袋又向左偏一下、向右晃回来，回正时小小地抖了一下。画面在这一下结束。

（上一段妈妈收住动作，这一段先给宝宝真正吃到一口，前面数次送勺才算有结果；但结尾不能变成妈妈终于把孩子管住了。镜九用双人近景把张嘴、勺入嘴、空勺撤回三步拍清，阿森回正和张嘴都发生在送勺之前，不能在晃头中强喂。那句台词是妈妈对自己刚才喂不上的轻笑，不要把它说成对宝宝的指责。镜十开头勺子已经在妈妈这一侧，孩子嘴里也没有勺，避开晃头时含勺的危险动作。最后三秒让妈妈开始舀下一口，阿森的小脑袋却独自重演刚才那种小幅偏、回、抖，落点由宝宝发动；动作一完就切黑，不给妈妈一个笑脸特写，也不添解释性旁白。这个重复和前几次的区别是妈妈此刻完全没有左右转脸，观众因此看懂他的小脑袋还在按自己的节奏动。最容易生成错的是让妈妈也同时晃，或让孩子甩头幅度越来越大；两种都会把最后这个独自多晃一下的笑点抹掉。）

**月龄核对（阿森 7 个月）**

| ✓ 本片用到的能力 | ✗ 本片不许出现的超龄动作 |
|---|---|
| 坐在固定餐椅里保持身体稳定，头有支撑地小幅偏转 | 把左右晃头演成有意识的「不要吃」或听懂妈妈的话 |
| 眼睛追随近处人脸和勺子的移动 | 与妈妈完全同步、按固定节拍精准摇头 |
| 手掌拍托盘、手指张合、蹬脚 | 站起、爬出餐椅、离开安全带或猛甩身体 |
| 张嘴接一小口温热辅食，在勺子撤走后继续小幅动头 | 含着勺子摇头，或被喂入未经吹凉的烫食 |

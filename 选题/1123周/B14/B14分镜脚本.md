# B14《一掉就哭》分镜脚本（四板块合并版）

> **文档说明**：选题 B14 · 片长 31 秒 · 场景 阿森家主卧·夜景（凌晨三点，单场单光）· 出镜 阿森（BB-01，满月）＋妈妈（MM-01，睡衣版）· 配套剧本 `选题/1123周/B14/B14剧本.md`（四轮清单法复核终稿）· 工作规范 `借鉴资料/分镜脚本指令v2.0_合并版.md`（v3.7：四板块单文件、即梦段落式、定稿图优先、画面化空间锁＋方位口径统一、静态关键帧先行验方位与段1 成片抽帧锚定、状态切换独立成拍、画风锁定、`@` 只用于点选素材）。
> **本片七条特有设定（务必先读）**：① **侧睡是物理前提，不是宝宝的动作**——满月的阿森不会自己翻身，侧躺是妈妈睡前摆好的起始姿态，嘴角朝下，奶嘴一松才顺重力滑到颊旁床单上；仰躺嘴角朝上含得稳、掉不了，全片所有侧躺都只能是这个已摆好的状态，绝不写出他自己翻身。② **妈妈的形象按本片指定，覆盖通用"笑嘻嘻"铁律**——凌晨三点哄睡场景，妈妈眼下一圈很重的青黑、一脸疲态、眼神迷离对不上焦；这是用户明确指定，定稿睡衣图自带笑脸但无黑眼圈，故走 B·修改只补黑眼圈这一恒定特征，疲态／迷离眼神由正文逐镜写死。③ **三次掉落三级递进**：一只脚蹬 → 两腿齐蹬 → 嘴角吧唧一声带两腿猛蹬，一次比一次重，动作全在满月硬能力内。④ **镜7、镜8 是同一件事的先后两拍**：特写拍"要掉"（顶出唇缝还没落）、近景拍"掉了"，两镜合起来是一次掉落，绝不能当成两次。⑤ **OS 只剩一句「接上了」**，压在正文写了出来的"含住＋连吸两下"上；此前"又要掉了"因镜内没铺垫奶嘴翘起、无画面依据已删，不许复活。⑥ **镜9 不拆镜**：落点是"妈妈手指松劲垂下"和"奶嘴滑出"几乎同时发生，拆成两镜巧合就散了；这一镜的动作归三拍走（抵住／合眼带松手／吧唧带滑出猛蹬哭），第五拍妈妈睁眼。⑦ **即梦段3 只有 7 秒**，低于规范 8 秒下限——它是完整落点链（抵住→睡着手垂→滑落→金句→合眼）不可拆，此为已知例外，如实标注、不悄悄圆。

### 四、有规则的设定（规则本身单列）

1. **掉落三级递进**：镜2 一只脚蹬（一级，全片最轻）→ 镜8 两腿齐蹬（二级）→ 镜9 嘴角吧唧一声＋两腿猛蹬（三级，最重）。第一级必须写轻，写重了后面没得涨；三级全在满月硬能力内。
2. **妈妈响应三级递进**：镜3–4 坐起的范围虽小但手要伸进拼接床 → 镜8 从被子里只抽手 → 镜9 手指直接抵在奶嘴上不撤。越熟练越好笑，但每次都是立即响应，不烦躁、不抱怨。
3. **"以为能睡了"的期待→落空**：镜6「又能睡觉了」是全片唯一一段大人松劲的时间，紧接镜7 的"要掉"特写和镜8 的掉落，喜剧张力全压在这一拍。
4. **信息优势**：镜7 特写只给奶嘴和嘴角、不给妈妈，妈妈到镜8 才惊醒；特写与惊醒放同一幅画就泄气。
5. **手的位置连续线**（本轮复核修复）：镜4 手退出拼接床、搭在床沿 → 镜5 还搭在床沿 → 镜6 收回大床枕边 → 镜8 从被子里伸进来 → 镜9 手指抵在奶嘴上、松劲垂到大床床面。段2末（镜6）手在大床枕边、段3起（镜9）手重新伸到奶嘴上，这中间有一次伸手动作，段3 承接块写死，不能让手凭空出现在奶嘴上。
6. **眼皮渐沉闭环**：镜4 眼睛又眯上 → 镜6 眼皮渐沉 → 镜9 合眼睡着 → 镜10 眼睛重新合上切黑。她从头到尾没真正醒过，这条线把黑眼圈的疲惫落地。
7. **三次掉落都在同一处**：奶嘴每次都滑到阿森颊旁的床单空处，离两张床之间的缝有明显距离，位置全片一致。

## 即梦实操 SOP（出片前照此勾一遍）

一、发给即梦的内容边界：只发板块三各段正文（段间承接块＋镜头＋录音点＋动画画风锁定后缀）；不发文档说明／结构层／后期清单／全局锁。**每条约束都靠正文里就地重写的那份生效**——光色锁看各镜「光照：」行、空间位置锁看承接块与「站位：」行、能力／口型／专项禁止看具体镜头画面行、脸型锁与画风锁看承接块末尾；发送前逐段确认无「同上／参考结构层／参考板块四」指代。特别核对画风：正文里绝不能同时出现「皮克斯动画」和「写实电影／胶片颗粒／真实质感」两套词。

二、开 3 个独立对话框（不要同对话续写）。**按「静态帧先行 → 段1 定锚」顺序**：①出视频前先按主机位／床侧机位出静态帧（图片7／8）、逐帧验方位（拼接床在西／大床在东／窗缝冷白在左／门缝暖黄在右／床侧机位从东朝西／两张脸清晰／背景无杂物），不对就重出静态帧直到对；②验对的静态帧作第一批锚帧，段1 照它生成；③段1 成片抽主机位／床侧机位方位锚帧（图片5／6）；④段2 传图＝基础四张＋静态帧图片7／8＋REF 图片5／6；段3 传图＝基础四张＋起手状态帧图片9（**不传旧段成片抽帧**，按 v3.5）；⑤每段出片与锚帧比对验收，不过只重出该段。方位以验对的为唯一基准，设计稿文字冲突时服从成片。

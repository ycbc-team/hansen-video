> **本片七条特有设定（务必先读）**：① **侧睡是物理前提，不是宝宝的动作**——满月的阿森不会自己翻身，侧躺是妈妈睡前摆好的起始姿态，嘴角朝下，奶嘴一松才顺重力滑到颊旁床单上；仰躺嘴角朝上含得稳、掉不了，全片所有侧躺都只能是这个已摆好的状态，绝不写出他自己翻身。② **妈妈的形象按本片指定，覆盖通用"笑嘻嘻"铁律**——凌晨三点哄睡场景，妈妈眼下一圈很重的青黑、一脸疲态、眼神迷离对不上焦；这是用户明确指定，定稿睡衣图自带笑脸但无黑眼圈、且发型是扎起的低马尾，故走 B·修改补两处恒定特征——眼下青黑＋把低马尾改成睡后散开的长发（仰躺睡着头发该散在枕面上），疲态／迷离眼神由正文逐镜写死。③ **三次掉落三级递进**：一只脚蹬 → 两腿齐蹬 → 嘴角吧唧一声带两腿猛蹬，一次比一次重，动作全在满月硬能力内。④ **镜7、镜8 是同一件事的先后两拍**：特写拍"要掉"（顶出唇缝还没落）、近景拍"掉了"，两镜合起来是一次掉落，绝不能当成两次。⑤ **OS 只剩一句「接上了」**，压在正文写了出来的"含住＋连吸两下"上；此前"又要掉了"因镜内没铺垫奶嘴翘起、无画面依据已删，不许复活。⑥ **镜9 不拆镜**：落点是"妈妈手指松劲垂下"和"奶嘴滑出"几乎同时发生，拆成两镜巧合就散了；这一镜的动作归三拍走（抵住／合眼带松手／吧唧带滑出猛蹬哭），第五拍妈妈睁眼。⑦ **即梦段3 只有 7 秒**，低于规范 8 秒下限——它是完整落点链（抵住→睡着手垂→滑落→金句→合眼）不可拆，此为已知例外，如实标注、不悄悄圆。⑧ **镜1 是全片唯一顶拍机位**（两张床正上方天花板处垂直向下俯拍），只用于开场一次交代睡姿全景：阿森在西侧拼接床侧卧、脸朝东紧贴大床，妈妈在大床靠拼接床的西半边仰躺、头朝北，两人肩背挨着；拼接床靠大床一侧无栏杆、两床贴死无缝，这是两人能挨在一起的前提，绝不画成中间隔着护栏或空隙；俯拍只看姿态与位置、看不清五官，故黑眼圈与疲态不在镜1 硬要求，留给镜3／4／6 去画。镜2–10 机位不变，掉落、表情、金句仍由主机位与床侧机位承担。⑨ **妈妈睡大床靠拼接床的西半边（本片特例，覆盖通用设定）**：通用资产设定是"爸爸睡靠拼接床的西半边、妈妈睡东半边"，但本片爸爸不出镜、妈妈要半夜伸手照看宝宝，故妈妈睡靠拼接床的西半边、紧挨着宝宝；全片所有"东半边"旧表述已作废。

### 四、有规则的设定（规则本身单列）

1. **掉落三级递进**：镜2 一只脚蹬（一级，全片最轻）→ 镜8 两腿齐蹬（二级）→ 镜9 嘴角吧唧一声＋两腿猛蹬（三级，最重）。第一级必须写轻，写重了后面没得涨；三级全在满月硬能力内。
2. **妈妈响应三级递进**：镜3–4 坐起的范围虽小但手要伸进拼接床 → 镜8 从被子里只抽手 → 镜9 手指直接抵在奶嘴上不撤。越熟练越好笑，但每次都是立即响应，不烦躁、不抱怨。
3. **"以为能睡了"的期待→落空**：镜6「又能睡觉了」是全片唯一一段大人松劲的时间，紧接镜7 的"要掉"特写和镜8 的掉落，喜剧张力全压在这一拍。
4. **信息优势**：镜7 特写只给奶嘴和嘴角、不给妈妈，妈妈到镜8 才惊醒；特写与惊醒放同一幅画就泄气。
5. **手的位置连续线**（本轮复核修复）：镜4 手退出拼接床、搭在床沿 → 镜5 还搭在床沿 → 镜6 收回大床枕边 → 镜8 从被子里伸进来 → 镜9 手指抵在奶嘴上、松劲垂到大床床面。段2末（镜6）手在大床枕边、段3起（镜9）手重新伸到奶嘴上，这中间有一次伸手动作——**段3 是状态转折段，用完整承接块把这个起手状态写死**（v4.2 写法 A），不能让手凭空出现在奶嘴上；段2 是普通连续段，只用轻量承接句，手的位置靠正文镜5／镜6 自己写清。
6. **眼皮渐沉闭环**：镜4 眼睛又眯上 → 镜6 眼皮渐沉 → 镜9 合眼睡着 → 镜10 眼睛重新合上切黑。她从头到尾没真正醒过，这条线把黑眼圈的疲惫落地。
7. **三次掉落都在同一处**：奶嘴每次都滑到阿森颊旁的床单空处、不滚向大床那一侧（两床贴死无缝、本就没有缝可滚），位置全片一致。

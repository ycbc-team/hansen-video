## 即梦实操 SOP（出片前照此勾一遍）

### 一、发给即梦的内容边界
- ✅ **只发「第一段 / 第二段 / 第三段」三段的正文**（每段 = 段间承接块 + 各镜头提示词 + 段尾录音点 + 胶片后缀）。
- ❌ **不发**以下四个模块（都是给你和剪辑用的规则/质检，即梦不需也不识别）：文档说明、固定空间与光影基准、后期合成清单、全局连续性锁。
- 每段内的机位/光照已写进镜头正文，无需额外粘贴"固定空间与光影基准"。

### 二、开 3 个独立对话框（不要同对话续写）
- 开 3 个新对话（或每次点"新建生成"），**不要在同一条对话里段一发完接着发段二**——即梦可能当成"视频续写/延长"，生成融合长片，破坏"独立片段 + 后期硬切"方案。
- **顺序生成**：段一 → 看片 → 段二 → 看片 → 段三。先抓系统性错误（如 @ 映射错、风格跑偏），避免 3 段全废。
- （想提速可并行；三段提示词互相独立，理论上可任意顺序，但并行会失去"先抓错误"缓冲。）

### 三、每段生成步骤（逐个对话框操作）
1. 复制该段全文（段间承接块 + 各镜头 + 录音点 + 胶片后缀）粘贴到即梦输入框。
2. 按下方"逐段传图表"上传本段要用到的参考图——**即梦不读本地文件名，每次生成都要重传**。
3. 把提示词里的 `@imageN` 用即梦的 `@` 选图功能**手动替换为对应缩略图**（不替换则占位失效，人物会随机生成）。
4. **确认不用即梦的"续写/延长"按钮**，直接生成 → 得到该段独立 clip。

**逐段传图表**（对照上方"参考图上传对照表"）：
- 段一（0:00–0:10）：传 **图片1、图片2、图片4、图片5、图片6**（5 张）
- 段二（0:10–0:20）：传 **图片1、图片2、图片3、图片4、图片5、图片6**（6 张）
- 段三（0:20–0:30）：传 **图片1、图片2、图片3、图片4、图片6**（5 张，不传图片5）

### 四、剪辑拼片
1. 三个 clip 导入剪映/PR，按时间码**硬切拼接**：段一尾（0:10）接段二头、段二尾（0:20）接段三头。
2. 两处硬切点本就是镜头切换（换机位），观众预期是"跳"，不突兀；段间承接块已把每段开头钉成上段结尾，进一步收敛首帧。
3. 叠加宝宝 OS 字幕（见《后期合成清单》区间 0:17–0:19 / 0:22–0:24），**不配音、不做口型**。
4. 片名「他认人了」与封面副标题后期合成。

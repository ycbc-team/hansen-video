# 家庭角色设定图 · 提示词合集

> 用途：为 **宝宝、爸爸、妈妈、爷爷、奶奶、外公、外婆** 各生成一张同款版式的「角色设定图」，共 7 张，可拼成一套家庭系列海报。  
> 版式统一为（**2026-11-06 新版「四卡版式」**，按「最终版.png」）：**左侧通高大特写 + 右上 4 张表情卡片（圆角浅底 + 暖黄描边 + 中英标签）+ 右下三视图（正/侧/背）**；**右侧细节栏与左上角标题全部取消**，只留几处手绘涂鸦。  
> 另附两张抖音主页配套图（头像 1:1 + 主页背景 16:9，三人温馨合照），见第 6 节。

## 0. 怎么用（三步）

1. **每张图单独生成一次，都靠上传图片决定人物和衣服，提示词里不写具体款式**。
   - 宝宝：传**四张**（脸 / 版式 / 衣服 / 口水巾）
   - 六位成人：传**三张**（本人照片 / 服装图 / **宝宝那张设定图当版式参考**），服装图平铺或本人穿着都可以；**如果出过一次"太写实"，第 4 张一定要加一张「你认可的那种三维家庭动画截图」**（大头大眼、圆脸、发块油亮）（详见 §1.5「成人版变照片红线」）
   - 全程一次只传一个人，别把全家人一起传进去。
2. 复制对应角色的提示词代码块，**只改「需替换」标注的几处**（年龄、发型、配饰）。**服装不用改字**——它只认上传的服装图。
3. **宝宝那张就是母版**。它已经是你认可的效果——后面 6 张成人图，都把它当「风格参考图」一起上传，一致性最稳。

> 七张都定稿之后，只想给某个人换衣服？直接跳到 **第 8 节**，有专用换装提示词。

> 提示：AI 对中文小标签的排版能力普遍不稳。建议先生成**不带文字**的干净版，再用设计工具（Canva / Figma / PPT）统一叠中英标签，成功率最高。

## 1. 全套统一视觉锚点（7 张都必须是这一套，不要改）

| 项目        | 统一设定                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 比例        | **4:3 横构图**（与宝宝参考图一致，不要 16:9）                                                                                               |
| 版式分区      | **左 33~35% 通高大特写 / 右上 4 张表情卡片 / 右下三视图 / 无细节栏、无标题，只有少量涂鸦**                                                                   |
| 服装来源      | **全部靠上传的服装图决定，提示词里不写款式**：宝宝 = 服装图 + 口水巾图；六位成人 = 各自的服装图                                                                      |
| 背景 · 宝宝   | 上半**米白墙面 + 半透纱帘**（虚化、发亮），地面铺**浅豆绿针织绒面地毯**，不放玩偶抱枕                                                                            |
| 背景 · 六位成人 | **与宝宝同一套**：浅暖米白墙面/纸 + 地面铺**同样的浅豆绿针织绒面地毯**，脚下自然柔和落影，无其他道具（这样七张能拼成一套）                                                         |
| 光线 · 宝宝   | **左上后方 45° 强侧逆光窗光**（比正面亮 1.5-2 档）+ 右前方环境漫反射补光；**背景比人物亮约 2 档、接近纯白**；浅景深                                                      |
| 光线 · 六位成人 | **柔和高调光**：左前上方 35~~40° 一大片柔光，整体明亮暖通透；脸两侧只留薄薄一层柔和暗面（最亮与最暗只差 0.5~~1 档），**不压暗半张脸、下巴下方不是硬投影而是淡阴影**；肩线与发块外轮廓一道柔光边；背景比人物亮 1~1.5 档 |
| 质感        | **电影级三维动画渲染**：次表面散射皮肤 + 暖桃红晕 + 唇鼻眼角的湿润高光、**头发成块发片且整层油亮**、布料有织物质感；**不是真实摄影，但也绝不是哑光塑料手办**                                     |
| 色调        | **暖白高调、高饱和**（约 4200-4500K），轻微过曝；宝宝那张背景接近纯白                                                                                  |
| 字体风格      | 表情卡下方两行字：英文粗体无衬线 + 中文小字，统一深棕色；**画面里不再有标题文字**                                                                                |

> 🎬 **全篇风格基调：动画电影角色设定，不是摄影。**  
> 长相来自照片，但**呈现方式必须是 3D 动画角色**：皮肤干净通透、色块过渡柔和、毛发成束可见、布料有版型但纹理适度简化。  
> **生成出来像真人照片 = 失败**，像劣质手办或 Q 版大头同样 = 失败。目标是「皮克斯/迪士尼正片里的角色定妆图」那种质感。

> 🧩 **为什么成人也要给版式参考图（重要）**  
> 只靠文字，分区比例只能"大概"，模型经常犯这几类错：三视图画成 2 个或 4 个、**表情卡少一两张或大小不一**、**表情卡跑到画面下方**、左侧大特写被压到一半宽、标签乱码、**自作主张加回右侧细节栏**。  
> 给了图 C 之后，模型做的是「照这张的结构重新填人」而不是「凭文字想象一张设定图」，**版式还原率会明显提高**，七张拼在一起才像一套。  
> 但图 C 有个副作用：**会把参考图里的人物脸和衣服一起带进来**。所以提示词里必须写死「图 C 只给版式、光线与背景，长相与服装一律作废」——这段别删。

> ⚠️ **如果出来「哑光平光」（最常见，也是这次那张的问题）**：不是模型不懂动画风，而是它**把光照当成了"把脸照亮"**，没有当"塑造体积"。四面光一起喂时，模型注意力全在排版和换装上，光影最先被牺牲。加这四句最有效，比写“高级”“精致”管用：
>
> 1. **直接指认**：`第三张是设定图，它左侧那张大特写是唯一的光影与材质基准，只学光与质感，不学脸和衣服`——模型对「照这张的光打」的服从度，远高于任何抽象描述；
> 2. 鼻尖、鼻梁、上唇、下唇、内眼角要有**边缘清晰的锐利白点**（这是从"哑光"变"水润"的唯一开关）；
> 3. **头发写成「成块成片的发片」、只在发块外缘勾一道被逆光打亮的边缘光**（这是从"假发套"变"有体积的发块"的唯一开关）。**别写「一束束分开、束间透出背景亮光」**——那会把头发推向写实胎发的细丝，是前几轮踩过的坑；
> 4. **背景比人物亮 2 档、接近过曝纯白**，人物是画面里最实的一块。  
>    这四条里只要缺「背景更亮」和「发丝/发块轮廓的透光」，出来就一定偏平——它们比肤色、比五官都更影响"像不像电影"。

> **如果模型还是给你写实照片**，按顺序加码：
>
> 1. 在提示词最前面顶一句：`3D animated character design sheet, Pixar / Disney style, stylized, NOT photorealistic, no photo texture`
> 2. 把【画质】段提到【版面】之前（权重更高的位置）
> 3. 换一个更擅长 3D 动画风的模型（即梦 / 可灵 / Seedream 的「3D 动画」或「皮克斯」风格选项），纯写实向的模型很难掰过来

> ✅ **七张用同一套背景**：上半**米白墙面 / 半透纱帘**，地面**浅豆绿针织绒面地毯**——宝宝和六位成人完全一致（这是「最终版.png」定下来的），拼版天然成套，不用再逐一调背景明度。  
> 若以后想让成人换成影棚纸，只改各段【九】里那一句就行，别动版式。  
> 拼版时若仍觉得割裂，见第 7 节「混排解法」。

## 1.5 动画感够不够？（视频项目必看）

> 直接回答：**现在这版是「中偏弱」——做动画视频会像真人素材加了层滤镜。** 下面给判断方法和 7 个加码开关。

**30 秒自测**：把图缩到 20% 大小看。**还像一张婴儿照片 = 动画感不够**；像"从动画电影里截的一帧" = 对了。再盯两个局部：**眼睛**是不是"被设计过的眼睛"（虹膜大、有两层、水光层厚、高光锐利）；**皮肤**是不是干净到找不到一处纹理颗粒。

**三档强度，视频建议「中偏强」**

| 档位          | 特征                                                                                                                                                  | 适用            |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| 轻（≈你现在这版）   | 五官、皮肤都接近照片，只有光和色偏电影感                                                                                                                                | 广告、需要"像真人"的场合 |
| **中偏强（推荐）** | 五官**按规则夸张**（眼睛宽高各 +10~12%、脸颊更饱满、鼻子缩小变平），**3 个比值锁死 + 脸型双向锁**；细节密度大幅降低：皮肤零纹理、**头发成块成片（不是一根根丝）**、鼻梁几乎不画、**虹膜约为眼裂高度的 90~95%（眼白主要留左右两侧）**、大块明暗 + 下巴下方有投影 | 动画短片、角色出镜视频   |
| 强（Q 版）      | 头身比 1:3、眼睛占脸 1/3、萌化                                                                                                                                 | 儿童向，不适合写实家庭题材 |

**关键认知：动画感可以动五官，规则是「锁比值、放尺寸」。**

「保留本人长相」的正确含义是：**不能换成市面上那种通用 AI 宝宝脸，必须以照片为起点来改造**——所以五官比例**是可以动的**，一点都不动，出来的就是真人比例，那才叫没动画感。

**必须锁死的 3 个比值（认人全靠这些，动一个就变陌生人）**

1. 两眼间距 ÷ 单眼宽度；
2. 眼睛在脸上的高度位置（发际线到下巴的百分比）；
3. 中庭长度（眉到鼻底）÷ 下庭长度（鼻底到下巴）。

> **宝宝的脸型与五官比例，直接以「已认可的成品图」为标准，不按照片锁**——因为照片的脸本身偏长偏窄，照搬就出「照片脸」；靠形容词夸张又没有标准，就会一圆一长地来回摆。**照片只管「是谁」，成品图管「长成什么样」**，这条比任何比值都管用（见 §3.0）。  
> 下面这 3 个比值**宝宝和成人都要守**。  
> **但「脸宽长比」不在其中**——宝宝的脸型按成品图重设（宽、短、肉），成人的脸型按动画标准重设（圆润的小饱满脸、脸宽 ≈ 脸高 × 0.95~1.0）。两头都锁：**不许削成瘦长脸 / 尖下巴 / 菱形脸**（写实感的主要来源），也**不许圆成一颗球**（Q 版）。

**可以放开的尺寸（按这个幅度夸张，不会丢人）**

| 项目 | 推荐夸张幅度                                                                                                                                                                                                       |
| -- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 眼睛 | **宝宝**：眼裂宽高**各 +10~12%**（硬上限 1.2 倍），虹膜 ≈ 眼裂高度的 **90~95%**，眼白左右各约 1/5<br />**成人**：眼裂**宽 +35~~40%、高 +30~~35%**（硬上限 1.45 倍），虹膜 **100%**，眼白左右各约 1/10。**成人眼睛的夸张幅度必须是宝宝的两倍多才有同样的「大眼感」——宝宝的眼睛天生就占脸大，成人的基准小得多。**     |
| 脸型 | **宝宝**：脸颊 +15%；最宽点在**鼻翼高度**，下巴缩短 5~8%，是**一个小而圆的面**<br />**成人**：脸宽 ≈ 脸高 × **0.95~1.0**（真人约 0.7）；**脸颊 +20~25%**（婴儿肥那种鼓）；最宽点在**颧骨下方脸颊那一带**；下颌一条大半径弧、下巴小而圆<br />**两头都不许越界：圆成正圆 / 大饼脸 ✗，长成椭圆 / 瓜子脸 / 上宽下窄的倒三角 ✗** |
| 鼻子 | 缩小 **15~20%**，鼻梁缩短，鼻头更圆                                                                                                                                                                                      |
| 嘴  | 唇更饱满，嘴宽变动控制在 ±10% 内                                                                                                                                                                                          |
| 头身 | **成人 5.5~6 头身**（真人成年人是 7.5 头身，这是「像照片」的第一信号）、头部 **+15~20%**；宝宝头身比**不低于 1:4.5**、四肢略短粗                                                                                                                          |
| 额头 | 略高、更圆                                                                                                                                                                                                        |

**红线（两条，任一条破了就要回调）**

- **「不是他」红线**（成人适用）：改动上面 3 个比值中的任何一个。宝宝不做这条——宝宝的脸型比例本就按成品图重设。
- **「变套娃」红线（往圆的一侧）**：① 虹膜填满眼裂、眼白消失；② 下颌线完全消失、脸圆成一颗球；③ **头身比低于 5.5（成人）/ 低于 4.5（宝宝）**；④ 眼裂上下被撑开、眼白四边都空。这四条是 Q 版的可观察特征，一旦出现，画面就从「皮克斯正片」掉到「低幼绘本」。
- **「变照片」红线（往写实的一侧，2026-11-06 新增，同样容易踩）**：① 脸拉长成椭圆 / 鹅蛋 / 瓜子脸，下半脸削窄成「上宽下窄的倒三角」；② 眼睛变小、眼裂细长、上眼睑盖住半个虹膜；③ 头发一根根细丝根根分明、像刺猬、露出稀疏头皮；④ 下巴正下方没有投影、整张脸亮度均匀；⑤ 鼻梁高、鼻翼立体、看得见鼻孔；⑥ 肤色偏蜜色 / 暖棕。**这六条一旦出现，出来的就是「修过图的婴儿照片」，不是动画角色——把成图缩到 20% 还认得出是照片，就是踩了。**
- **「变照片」红线 · 成人版（2026-11-06 新增，成人比宝宝更容易踩）**：① **真人 7.5 头身比例**（成人写实的第一信号，比脸型还准）；② 脸瘦长 / 尖下巴 / 菱形脸 / 颧骨与下颌角勾出骨点；③ **脸上有法令纹、眼袋、鱼尾纹、抬头纹、颈纹、手背血管**（动画角色用轮廓和色块演年龄，不画皱纹）；④ 头发一根根发丝分明、被风吹散的绒毛感；⑤ **柔光箱 + 反光板那种正面人像布光、脸上亮度均匀**；⑥ 皮肤"细腻通透"到看得见质感。**成人出图的默认结果就是「精修人像照」，缩到 20% 像证件照 / 婚纱照，就是踩了。**

**放大眼睛时有个容易忽略的细节**：只能**向脸的外侧扩**，眼裂内侧到鼻梁的距离必须保持不变。眼睛往内长，眼距视觉上就变窄，会显得斗鸡眼、也会丢识别度。

**「像斗鸡眼」不等于眼距太近——先分清这两个问题（2026-11-06 实测）**

|          | 眼距（两眼间距）                         | 瞳孔朝向（虹膜在眼裂里的位置）                        |
| -------- | -------------------------------- | -------------------------------------- |
| **表现**   | 两只眼睛整只往中间靠，内眼角几乎贴在一起             | 眼睛位置正常，但**一只眼珠偏内、一只偏外**，或某一侧眼珠贴住内眼角    |
| **要不要动** | **不要动**。眼距÷眼宽是 4 个锁定比值之一，改了就不像本人 | **要动**。这是可以也必须修的                       |
| **怎么修**  | 不动                               | 让两只虹膜在各自眼裂里的相对位置**一致且对称**，都在正中偏外 5~10% |

判断口诀：**看「眼珠在眼眶里的位置」是否左右对称，而不是看「两只眼睛隔多远」。** 多数「像对眼」的图，眼距其实是对的，错的是瞳孔——尤其是头有 3/4 转动时，眼睛跟着头看出去，远侧眼的眼珠就会贴住内眼角，一下就变成对眼。

在这套形变规则之上，再叠加下面 7 个「渲染语言」开关：

1. **细节密度（最有效）**：去掉一切照片纹理——毛孔、绒毛、皮肤颗粒、单根细碎发丝、布料纤维。**真实感来自细节多，动画感来自细节少但每处都精致**，这条搞反就永远像照片。
2. **形体归纳**：脸颊、额头归纳为饱满球面与穹顶，四肢是柔和圆柱，**手指短粗肉感、指节不明显、手背有小凹窝**（不要画成缩小版成人的手——这是实测最容易翻的一处）；**剪影是一条连续柔弧**，**下颌线保留一点转折**（不要圆成一颗球），不出现颧骨尖、鼻骨棱这类骨点与硬折角。
3. **五官简化**：鼻梁只留一条柔和起伏（不画鼻骨与鼻翼软骨）、人中一小段浅凹、上下唇是两片饱满曲面、耳廓外圈 + 一条内弧。
4. **眼睛：放大 + 做设计**——**宝宝**眼裂宽高各 +10~~12%（上限 1.2 倍）、虹膜 90~~95%；**成人**眼裂宽 +35~~40%、高 +30~~35%（上限 1.45 倍）、虹膜 100%，眼白只剩左右两侧各约 1/10 的窄条；虹膜两层（深棕外环 + 琥珀内环）+ 放射纤维；角膜上盖一层**厚而清晰的水光层**；高光点是**锐利的白色多边形**；上眼睑有厚度并在眼白投一条淡影；睫毛**成簇**不成丝。**注意：放大的是尺寸，两眼间距与眼睛高度位置不能变。**
5. **光影简化**：大块明暗替代处处柔和渐变；亮部干净、暗部通透偏暖，边缘光更明显。
6. **色彩加一档**：饱和度再提 10-15%，暗部偏暖红，不用灰黑。
7. **表情夸张半档**：笑时嘴角更开、苹果肌更高、下眼睑更弯——动画角色的表情幅度天然比真人大 20-30%。

**实测校准：跑出来偏 Q 版时，先查这三处（2026-11-06 实测）**

第一轮按 +15~20% 跑出来的图，三个画面都在，但整体偏「低幼绘本」而不是「皮克斯正片」。三个可观察的标志，按这个顺序查：

| 现象                | 说明                      | 怎么调                                                                                  |
| ----------------- | ----------------------- | ------------------------------------------------------------------------------------ |
| **虹膜填满眼裂、眼白只剩一丝** | 这是「套娃化」的第一开关，比眼睛尺寸本身更致命 | 虹膜收到**与上下眼睑几乎相接或只留一线**，**眼白一定留在左右两侧**（宝宝各约 1/5 眼裂宽，成人各约 1/8~1/6）——**是留「缝」，不是留「一大圈」** |
| **下颌线完全消失、脸圆成球**  | 第二开关，丢了下颌就没了成人/婴儿的骨相差异  | 下巴只缩 **5~8%**，下颌**保留一点转折**                                                           |
| **头发一根根细丝、像刺猬**   | 这才是写实化的信号，造型问题          | 改成「**成块成片的发片**：片内实心不透光、片间深色缝隙、外缘光滑大弧、整体油亮高光」                                         |

**判定顺序**：先看眼白还在不在 → 再看下颌线还在不在 → 最后才看眼睛大小。眼白和下颌对了，眼睛哪怕大一点也还是角色设定图；这两样丢了，眼睛再准也像套娃。

**做视频的三个坑**

- **视频模型会把真实感加回来**（运动模糊、噪点、轻微抖动）。所以静帧要**故意再卡通一档**，动起来才刚好；按"静帧看着满意"定稿，成片一定偏写实。
- **一张设定图撑不住一个视频**。视频会转头、抬下巴、拉远，必须补角度图：**3/4 侧脸、低角度仰拍、室内暖光**各一张，风格与设定图完全一致，否则第一个转身就崩。
- **资产要能复现**。把 5 个锚点写死：发型走向与发量、眼距与眼裂长度、鼻梁起伏、唇形、脸颊体积。每次生成都带同一张设定图 + 同一段描述，别临时改词。

### ⚠️ 成人版的风格定位（2026-11-07 按附图重定）

**目标不是「皮克斯正片的克制写实」，而是附图那种「三维家庭动画的甜」**——具体是五个肉眼能判断的特征：

| 特征     | 具体长什么样                                                                                         |
| ------ | ---------------------------------------------------------------------------------------------- |
| **头大** | 5.5~~6 头身，头比真人比例大 15~~20%，脖子细一点、肩略窄                                                            |
| **眼大** | 眼宽 ≈ 脸宽的 1/3（真人约 1/6），虹膜几乎填满眼裂，眼白只剩左右两条窄缝，睫毛成簇上翘                                               |
| **脸短** | 脸宽 ≈ 脸高（发际线到下巴）× 0.95~1.0、**下庭压缩**（鼻底到下巴 < 眉头到鼻底）、下巴极小极短；脸颊有软软的婴儿肥。**脸一长就回到写实，这是「像不像动画」的第一判据** |
| **发亮** | 成块的发片 + 一整层油亮高光（像打了发蜡），不是一根根发丝                                                                 |

**一句话：要的是「放大版的可爱」，不是「缩小版的真实」。**

### ⚠️ 成人版为什么天生更容易画成「写实照片」

这不是提示词没写好那么简单，有三个结构性原因：

1. **训练数据里成年人的真实照片压倒性地多。** 婴儿的"动画化"样本（皮克斯宝宝、动画片婴儿）远比成年人多；一提到"38 岁中国女性"，模型的第一反应就是人像摄影。
2. **成年人写实的五个信号，模型默认全都给你**：7.5 头身（真人比例）、**眼睛只有真人那么大**（最关键，比脸型还准）、一根根分明的发丝、靠法令纹和眼袋演年龄、皮肤上一点点锐利白高光。这五样只要留一样，整张就掉回写实。
3. **图 C（宝宝设定图）压不住成人。** 那张是婴儿，模型不会把婴儿的动画化程度迁移到成年人身上——它只会把版式和背景搬过来，脸照样按真人画。而且**宝宝的眼睛天生就占脸大（真人宝宝眼宽≈脸宽 1/5），成人要达到同样的「大眼感」，夸张幅度必须翻倍**（成人眼宽要到脸宽 **1/3**、虹膜直接填满）——这就是为什么宝宝版 +10~~12% 就够，成人版照抄那串数字就还是真人。**而且成人还要多做一件事：把脸压短**——宝宝的脸本来就短，成人的脸天生偏长，不改脸宽长比，眼睛再大也还是「大眼真人」。

**所以成人版现在多了两件东西：**

- **一套「五把锁」写在提示词里**：**5.5~6 头身**（真人 7.5，这是最硬的一条）/ **眼睛必须比真人大一档**（眼宽 ≈ 脸宽 1/3、虹膜 100% 填满）/ **脸型压成一个短圆**（脸宽 ≈ 脸高 × 0.95~1.0、下庭压缩、下巴极小）/ 骨相只用明暗不勾骨点 / 年龄靠形体不靠皱纹。详见各段【二】【三】。

- **一套「五官也要缩小」的配套**（2026-11-08 按妈妈图 2 补的）：脸压短、眼放大之后，**鼻子缩小 15~~20% 且变短、嘴缩小到脸宽 1/4~~1/4.5、耳朵缩小 15%、眉毛简化成实心弧带、苹果肌做成两个圆球 + 淡腮红**。这六处不同步，脸会显挤、显老，动画感立刻掉一半。

- 目标：**一眼认出是图 A 本人，但头身比、脸型、骨相、眼睛、皮肤、头发全部是动画片那一套**——像那种三维动画家庭短片里的爸爸妈妈（大眼睛、圆脸、发块有油亮光泽），不像一张精修证件照。
【三、眼睛（只此一段）】
- **这是全篇最重要的一条：眼睛必须明显大于真人，而且要「大到有点不真实」。** 以图 A 的眼睛为基准，眼裂**宽度 +35~40%、高度 +30~35%**（宽略多于高，保持**杏仁形偏圆**——内眼角留一个小尖、外眼角略上扬，整体接近圆但不要真画成正圆），硬上限 1.45 倍，只向脸外侧扩；**两眼间距与眼睛高度位置不变**，不许为了显年轻把眼往中间挤。判据：**单只眼睛的宽度约等于脸宽的 1/3（不得小于 1/3.4）、高度约等于脸宽的 1/4.2**——**这个尺寸放到真人脸上是夸张的、甚至有点过头，那才是对的；如果你看着觉得「挺自然」，就是没做到。** 眼裂上下要开够，**上眼睑只轻轻压住虹膜上缘**，不许把眼睛压成细缝、不许上眼睑盖住半个虹膜。**眼睛一旦回到真人大小，整张脸就回到真人；眼睛一小，脸就立刻显长。**
- 虹膜要**大到接近填满**——直径约为眼裂高度的 **100%**，**与上下眼睑上下相接**（最多只留一条发丝细的缝）；眼白只剩**左右两侧各约 1/10 眼裂宽**的窄条，加内眼角一小块楔形眼白。**判据：眯起眼看，眼睛是两颗几乎纯黑的圆，眼白像两道细边——不是两个大白眼球中间各嵌一个黑点。**两头都禁：**不许虹膜小、眼白四边都空**（会变呆、变写实、眼神散），也**不许把眼裂上下撑开到露出大片眼白**（会变圆眼、变 Q 版）；两只虹膜在各自眼裂里的位置一致对称、都在正中偏外 5~10%，「虹膜外缘到眼裂外缘」距离左右相等，任何一只都不许贴内眼角。
- 双眼平视镜头、视线平行；头部 3/4 转动或微侧头时眼球回转看镜头，不许顺头看出去。
- 材质：虹膜深棕→琥珀、带放射纤维纹；角膜上盖一层**厚而边缘清晰**的水光层；一对**干净的白色圆点高光**（一大一小、边缘略柔）左右对称——像动画角色那样明确的两点，不是细碎的反光；上眼睑有厚度并在眼白投淡影；**睫毛明显可见——上睫毛 5~7 簇、略向上翘，眼尾两三簇略长**。（可略强调睫毛成簇与眼尾形状，眼型与眼距不得改变。）
- 禁止内斜 / 外斜 / 对眼、虹膜死黑、玻璃珠、眼神呆滞。

【四、光与皮肤】
- **光源几何**：**柔和高调光**——主光是**画面左前上方约 35~40° 打下来的一大片柔光**（像一扇大窗），整体明亮、通透、暖；人物的受光面均匀饱满，脸的两侧只留**薄薄一层柔和的暗面**做出体积，不做明暗对半的硬分界；肩线与发块外轮廓上轻轻勾一道柔光边。**判据（三条一起看）：① 脸上最亮处与最暗处的亮度差只有 0.3~0.8 档，过渡非常柔（**认可的那版成人图几乎是平光，宁可更平、不要更立体**）；② 下巴正下方只有一层很淡的柔和阴影，不是一块硬的黑投影；③ 整张脸被压暗一半、或出现明显的一侧深一侧亮，就是打光太硬——那是电影侧逆光，不是这套图要的「甜」。**
- **明暗结构**：**以柔和的体积过渡为主**——靠鼻梁、脸颊、下颌那些圆润起伏做出立体感，不靠硬明暗切分；亮部干净不死白，暗部通透偏暖不发灰。**判据：眯眼看能看出脸的圆润起伏（鼻子、苹果肌、下巴的圆），但看不出「一半亮一半暗」的那条分界。**
- **皮肤高光（要润、不要一点点扎眼的白）**：额头一片大柔光；鼻梁一条竖向柔光；鼻尖一个**很小很柔**的亮点（边缘化开，不要锐利小白点）；颧骨一片柔和亮面；上下唇各一点温润亮光；内眼角一点水光。**高光是成片的柔光，不是一颗颗硬点**——但要「润」，绝不是哑光。
- **肤色**：**奶白偏象牙**（明度高、干净、微微偏冷，不是蜜色 / 暖棕 / 红铜底），颧骨有淡淡红晕，淡妆、唇色自然；**皮肤是一整片干净色块，过渡像手绘渐变，没有一条线状纹路**；不要冷调发青。
- **色调**：**暖调、低饱和的粉嫩通透**——整体高明度、干净柔和，暗部带暖不发灰；**不要浓艳、不要高饱和、不要糖水锐色**，饱和度向图 C 那张宝宝图看齐。

【五、头发】

- **发色锁**：照片什么色就是什么色，**不许整体漂浅成棕 / 栗 / 黄褐**；两鬓若有少量灰白，以照片为准；逆光**只在发块的整圈外轮廓**形成一道明亮边缘光，**发块内部不透光、不许背景亮光从发缝里穿过来**、不许整头呈现半透明。
- **发块，不是发丝（最容易被忽略的一条）**：头发是**成块成片**的——由若干**大发片**叠成，一片由十几根发丝**粘成一个整体**，**片与片之间是明显的深色缝隙，片内部实心、不透光**；发片外缘是**光滑的大弧线**，只在最外轮廓留 3~5 根**粗而短的挑发**；发块表面有一层**整体的油亮高光**（像打了发蜡），不是一根根发丝各自反光。发际线自然、鬓角与后颈干净。**禁止发丝一根根数得清、禁止束间透出背景光、禁止被风吹散的绒毛感、禁止真实的毛发质感、禁止假发套。灰白发同样成块成片。**

【二、人物：这是「动画片里的成年人」，不是精修人像】
约 66 岁的中国男性，体态微驼但站姿自然端正。
**成年人的真实照片在训练数据里压倒性地多——不按下面这些硬指标写，模型一定给你一张精修人像照。缺一条就掉回写实：**
- **头身比 5.5~6 头身**（真人成年人是 7.5 头身，这是「像照片」的第一信号）：**头部比照片 +15~20%**、躯干与腿相对缩短、肩宽略收；**低于 5.5 会变 Q 版儿童、高于 6.5 会变真人**，两头都不许越界。判据：三视图里从头到脚大约放得下 5 个半到 6 个头。
- **脸型按动画标准重设，不按照片锁比例——这张脸的关键词是「短」**：**一个接近正圆的短脸**——**脸宽 ≈ 脸高（发际线到下巴）的 0.95~1.0 倍**（真人照片多在 0.7 上下；**脸一长，整张图立刻掉回写实——这是这一版最常犯的错**）；**最宽点在颧骨到脸颊那一带**，比太阳穴明显宽一截；**下颌从耳垂到下巴只是一小段弧**——半径极大、弧长极短，几乎一拐弯就到下巴，中途不内凹、不出现下颌角折点；**下巴极小、极短**：宽度约等于两眼内眼角间距，高度只有嘴唇到下巴那一小段，圆润地收住、不许有向下拉长的尖；**下庭压缩**——**鼻底到下巴的垂直距离明显小于眉头到鼻底**（真人接近 1:1，这一版按 0.75:1 画）；**脸颊体积 +25~30%**，把下半张脸横向撑开。**判据：把脸的剪影单独描出来，应该是一个横着略扁的短蛋形，不是竖着的长蛋形；从眉毛到下巴的高度，明显小于发际线到眉毛高度的两倍。** **两头都不许越界**：不许削成尖下巴 / 瘦长脸 / 菱形脸 / 长中庭（写实感的主要来源），也不许圆成一颗球（Q 版）。**照片本人偏瘦偏长的，一律改成这样。**
- **五官必须同步「缩小一档、简化一层」**（脸压短、眼放大之后，剩下这几处不变小，脸就显挤、显老——这是「满意样张」和「写实样张」之间最容易被忽略的一处差别）：**鼻子**缩小 15~20%、**鼻子要短**（鼻底位置偏上，鼻子只占脸高的一小段），只有一个小圆鼻头 + 两侧各一条浅弧，**鼻梁几乎不画、不勾鼻翼外轮廓、不画鼻孔**；**嘴缩小到嘴宽 ≈ 脸宽 1/4~1/4.5**（真人约 1/3），上唇薄、下唇略厚、唇峰清楚、唇线干净，**不画唇纹、不画口角纹**；**耳朵**缩小约 15%，上缘与眉毛齐平，正面几乎被头发挡掉一半；**眉毛**简化成一条**实心的深色弧带**——眉头略粗、眉尾渐细、边缘干净，**不画一根根毛流、不画杂毛、不画眉尾飞出去的细笔触**；**苹果肌做成两个明确的圆球面**，各带一片淡粉红晕（腮红不超过眼外角的垂线），这是「甜」的来源之一。
- **骨相只用明暗、不勾骨点**：颧骨、下颌角、眉骨、鼻骨、锁骨**都不勾轮廓线**，只靠明暗与转折表现；剪影是一条连续柔弧，脸上不出现硬折角、不出现凹陷的太阳穴。
- **年龄靠形体，不靠皱纹**：年龄感锁在 **62-70 岁**，但只由**发色、体态、气色、皮肤明暗结构**表达。**法令纹、眼袋、泪沟、鱼尾纹、抬头纹、眉间纹、颈纹、手背血管与指关节褶皱一律不画**——皮肤是**一整片干净的色块**，只有明暗与红晕，没有一条线状纹路。（皮克斯的成年与老年角色从来是用轮廓和色块演年龄，不是画皱纹。）白发与体态已经说明年龄；面颊下部略松弛**只靠体积的高低表现**，不画线。
- **手与耳廓也简化**（鼻子、嘴、眉已在上面那条写清，这里不重复）：手指修长但**指节不画、不画手背血管与褶皱**，指腹圆润，指甲简化成一个圆角小面；人中一小段浅凹；耳廓只有外圈 + 一条内弧。
- **细节密度（真实感来自细节多，动画感来自细节少但每处精致）**：皮肤不得有任何照片纹理（毛孔、绒毛、颗粒、色斑噪点），过渡像手绘渐变；头发成块成片、不画单根发丝；布料不做纤维扫描。
- **认人只靠这几样**：发际线形状、眉形与浓淡、眼型的走向、鼻头与唇的具体形状、耳形、肤色与红晕、体型胖瘦的整体感觉；另加 **两眼间距 ÷ 单眼宽、眼睛高度位置、中庭 ÷ 下庭** 这三个比值不变。
- 目标：**一眼认出是图 A 本人，但头身比、脸型、骨相、眼睛、皮肤、头发全部是动画片那一套**——像那种三维动画家庭短片里的爸爸妈妈（大眼睛、圆脸、发块有油亮光泽），不像一张精修证件照。
【三、眼睛（只此一段）】
- **这是全篇最重要的一条：眼睛必须明显大于真人，而且要「大到有点不真实」。** 以图 A 的眼睛为基准，眼裂**宽度 +35~40%、高度 +30~35%**（宽略多于高，保持**杏仁形偏圆**——内眼角留一个小尖、外眼角略上扬，整体接近圆但不要真画成正圆），硬上限 1.45 倍，只向脸外侧扩；**两眼间距与眼睛高度位置不变**，不许为了显年轻把眼往中间挤。判据：**单只眼睛的宽度约等于脸宽的 1/3（不得小于 1/3.4）、高度约等于脸宽的 1/4.2**——**这个尺寸放到真人脸上是夸张的、甚至有点过头，那才是对的；如果你看着觉得「挺自然」，就是没做到。** 眼裂上下要开够，**上眼睑只轻轻压住虹膜上缘**，不许把眼睛压成细缝、不许上眼睑盖住半个虹膜。**眼睛一旦回到真人大小，整张脸就回到真人；眼睛一小，脸就立刻显长。**
- 虹膜要**大到接近填满**——直径约为眼裂高度的 **100%**，**与上下眼睑上下相接**（最多只留一条发丝细的缝）；眼白只剩**左右两侧各约 1/10 眼裂宽**的窄条，加内眼角一小块楔形眼白。**判据：眯起眼看，眼睛是两颗几乎纯黑的圆，眼白像两道细边——不是两个大白眼球中间各嵌一个黑点。**两头都禁：**不许虹膜小、眼白四边都空**（会变呆、变写实、眼神散），也**不许把眼裂上下撑开到露出大片眼白**（会变圆眼、变 Q 版）；两只虹膜在各自眼裂里的位置一致对称、都在正中偏外 5~10%，「虹膜外缘到眼裂外缘」距离左右相等，任何一只都不许贴内眼角。
- 双眼平视镜头、视线平行；头部 3/4 转动或微侧头时眼球回转看镜头，不许顺头看出去。
- 材质：虹膜深棕→琥珀、带放射纤维纹；角膜上盖一层**厚而边缘清晰**的水光层；一对**干净的白色圆点高光**（一大一小、边缘略柔）左右对称——像动画角色那样明确的两点，不是细碎的反光；上眼睑有厚度并在眼白投淡影；**睫毛明显可见——上睫毛 5~7 簇、略向上翘，眼尾两三簇略长**。上眼睑略松垂（老年特征，用体积不用线条），虹膜比例仍按 **95~100%**。
- 禁止内斜 / 外斜 / 对眼、虹膜死黑、玻璃珠、眼神呆滞。

【四、光与皮肤】
- **光源几何**：**柔和高调光**——主光是**画面左前上方约 35~40° 打下来的一大片柔光**（像一扇大窗），整体明亮、通透、暖；人物的受光面均匀饱满，脸的两侧只留**薄薄一层柔和的暗面**做出体积，不做明暗对半的硬分界；肩线与发块外轮廓上轻轻勾一道柔光边。**判据（三条一起看）：① 脸上最亮处与最暗处的亮度差只有 0.3~0.8 档，过渡非常柔（**认可的那版成人图几乎是平光，宁可更平、不要更立体**）；② 下巴正下方只有一层很淡的柔和阴影，不是一块硬的黑投影；③ 整张脸被压暗一半、或出现明显的一侧深一侧亮，就是打光太硬——那是电影侧逆光，不是这套图要的「甜」。**
- **明暗结构**：**以柔和的体积过渡为主**——靠鼻梁、脸颊、下颌那些圆润起伏做出立体感，不靠硬明暗切分；亮部干净不死白，暗部通透偏暖不发灰。**判据：眯眼看能看出脸的圆润起伏（鼻子、苹果肌、下巴的圆），但看不出「一半亮一半暗」的那条分界。**
- **皮肤高光（要润、不要一点点扎眼的白）**：额头一片大柔光；鼻梁一条竖向柔光；鼻尖一个**很小很柔**的亮点（边缘化开，不要锐利小白点）；颧骨一片柔和亮面；上下唇各一点温润亮光；内眼角一点水光。**高光是成片的柔光，不是一颗颗硬点**——但要「润」，绝不是哑光。
- **肤色**：偏暖的黄调肤色，颧骨与鼻头有自然血色；**老年斑只作为极淡的小块色斑出现（不超过五处、边缘柔），绝不画线状皱纹**；皮肤是一整片干净色块，松弛只靠大块的明暗起伏表现。
- **色调**：**暖调、低饱和的粉嫩通透**——整体高明度、干净柔和，暗部带暖不发灰；**不要浓艳、不要高饱和、不要糖水锐色**，饱和度向图 C 那张宝宝图看齐。

【五、头发】
- 发型发量按图 A：黑色短发、梳理整齐，发际线自然后移；发量按照片，不许画得更稀。
- **头发不许「夹脸」——这条比蓬不蓬更重要**：头发顺着头骨轮廓梳理（中分 / 侧分 / 齐耳都按照片来），**在脸颊两侧与脸的外轮廓之间留出空隙**——不要把头发压到脸颊上、不要让两缕头发贴着内脸颊垂下来，那等于给脸加了一副竖框，脸再短也会被看成长的；长发自然垂在肩前、发尾带一点向外的柔弧；**发根要立起来、头顶不许塌**，但**不要为了显脸小去做额外的蓬松外扩**（顺直贴头完全可以；发型本身带卷度就按照片）。外轮廓是饱满的弧，不是两条紧贴脸颊的直线。
- **发色锁**：照片什么色就是什么色，**不许整体漂浅成棕 / 栗 / 黄褐**；灰白比例以照片为准，不要整头染黑、也不要全白；逆光**只在发块的整圈外轮廓**形成一道明亮边缘光，**发块内部不透光、不许背景亮光从发缝里穿过来**、不许整头呈现半透明。
- **发块，不是发丝（最容易被忽略的一条）**：头发是**成块成片**的——由若干**大发片**叠成，一片由十几根发丝**粘成一个整体**，**片与片之间是明显的深色缝隙，片内部实心、不透光**；发片外缘是**光滑的大弧线**，只在最外轮廓留 3~5 根**粗而短的挑发**；发块表面有一层**整体的油亮高光**（像打了发蜡），不是一根根发丝各自反光。发际线自然、鬓角与后颈干净。**禁止发丝一根根数得清、禁止束间透出背景光、禁止被风吹散的绒毛感、禁止真实的毛发质感、禁止假发套。灰白发同样成块成片。**

- **认人只靠这几样**：发际线形状、眉形与浓淡、眼型的走向、鼻头与唇的具体形状、耳形、肤色与红晕、体型胖瘦的整体感觉；另加 **两眼间距 ÷ 单眼宽、眼睛高度位置、中庭 ÷ 下庭** 这三个比值不变。
- 目标：**一眼认出是图 A 本人，但头身比、脸型、骨相、眼睛、皮肤、头发全部是动画片那一套**——像那种三维动画家庭短片里的爸爸妈妈（大眼睛、圆脸、发块有油亮光泽），不像一张精修证件照。
【三、眼睛（只此一段）】
- **这是全篇最重要的一条：眼睛必须明显大于真人，而且要「大到有点不真实」。** 以图 A 的眼睛为基准，眼裂**宽度 +35~40%、高度 +30~35%**（宽略多于高，保持**杏仁形偏圆**——内眼角留一个小尖、外眼角略上扬，整体接近圆但不要真画成正圆），硬上限 1.45 倍，只向脸外侧扩；**两眼间距与眼睛高度位置不变**，不许为了显年轻把眼往中间挤。判据：**单只眼睛的宽度约等于脸宽的 1/3（不得小于 1/3.4）、高度约等于脸宽的 1/4.2**——**这个尺寸放到真人脸上是夸张的、甚至有点过头，那才是对的；如果你看着觉得「挺自然」，就是没做到。** 眼裂上下要开够，**上眼睑只轻轻压住虹膜上缘**，不许把眼睛压成细缝、不许上眼睑盖住半个虹膜。**眼睛一旦回到真人大小，整张脸就回到真人；眼睛一小，脸就立刻显长。**
- 虹膜要**大到接近填满**——直径约为眼裂高度的 **100%**，**与上下眼睑上下相接**（最多只留一条发丝细的缝）；眼白只剩**左右两侧各约 1/10 眼裂宽**的窄条，加内眼角一小块楔形眼白。**判据：眯起眼看，眼睛是两颗几乎纯黑的圆，眼白像两道细边——不是两个大白眼球中间各嵌一个黑点。**两头都禁：**不许虹膜小、眼白四边都空**（会变呆、变写实、眼神散），也**不许把眼裂上下撑开到露出大片眼白**（会变圆眼、变 Q 版）；两只虹膜在各自眼裂里的位置一致对称、都在正中偏外 5~10%，「虹膜外缘到眼裂外缘」距离左右相等，任何一只都不许贴内眼角。

- 禁止内斜 / 外斜 / 对眼、虹膜死黑、玻璃珠、眼神呆滞。

【四、光与皮肤】
- **光源几何**：**柔和高调光**——主光是**画面左前上方约 35~40° 打下来的一大片柔光**（像一扇大窗），整体明亮、通透、暖；人物的受光面均匀饱满，脸的两侧只留**薄薄一层柔和的暗面**做出体积，不做明暗对半的硬分界；肩线与发块外轮廓上轻轻勾一道柔光边。**判据（三条一起看）：① 脸上最亮处与最暗处的亮度差只有 0.3~0.8 档，过渡非常柔（**认可的那版成人图几乎是平光，宁可更平、不要更立体**）；② 下巴正下方只有一层很淡的柔和阴影，不是一块硬的黑投影；③ 整张脸被压暗一半、或出现明显的一侧深一侧亮，就是打光太硬——那是电影侧逆光，不是这套图要的「甜」。**
- **明暗结构**：**以柔和的体积过渡为主**——靠鼻梁、脸颊、下颌那些圆润起伏做出立体感，不靠硬明暗切分；亮部干净不死白，暗部通透偏暖不发灰。**判据：眯眼看能看出脸的圆润起伏（鼻子、苹果肌、下巴的圆），但看不出「一半亮一半暗」的那条分界。**
- **皮肤高光（要润、不要一点点扎眼的白）**：额头一片大柔光；鼻梁一条竖向柔光；鼻尖一个**很小很柔**的亮点（边缘化开，不要锐利小白点）；颧骨一片柔和亮面；上下唇各一点温润亮光；内眼角一点水光。**高光是成片的柔光，不是一颗颗硬点**——但要「润」，绝不是哑光。

【二、人物：这是「动画片里的成年人」，不是精修人像】
约 62 岁的中国女性，体态轻盈、站姿自然。
**成年人的真实照片在训练数据里压倒性地多——不按下面这些硬指标写，模型一定给你一张精修人像照。缺一条就掉回写实：**
- **头身比 5.5~6 头身**（真人成年人是 7.5 头身，这是「像照片」的第一信号）：**头部比照片 +15~20%**、躯干与腿相对缩短、肩宽略收；**低于 5.5 会变 Q 版儿童、高于 6.5 会变真人**，两头都不许越界。判据：三视图里从头到脚大约放得下 5 个半到 6 个头。
- **脸型按动画标准重设，不按照片锁比例——这张脸的关键词是「短」**：**一个接近正圆的短脸**——**脸宽 ≈ 脸高（发际线到下巴）的 0.95~1.0 倍**（真人照片多在 0.7 上下；**脸一长，整张图立刻掉回写实——这是这一版最常犯的错**）；**最宽点在颧骨到脸颊那一带**，比太阳穴明显宽一截；**下颌从耳垂到下巴只是一小段弧**——半径极大、弧长极短，几乎一拐弯就到下巴，中途不内凹、不出现下颌角折点；**下巴极小、极短**：宽度约等于两眼内眼角间距，高度只有嘴唇到下巴那一小段，圆润地收住、不许有向下拉长的尖；**下庭压缩**——**鼻底到下巴的垂直距离明显小于眉头到鼻底**（真人接近 1:1，这一版按 0.75:1 画）；**脸颊体积 +25~30%**，把下半张脸横向撑开。**判据：把脸的剪影单独描出来，应该是一个横着略扁的短蛋形，不是竖着的长蛋形；从眉毛到下巴的高度，明显小于发际线到眉毛高度的两倍。** **两头都不许越界**：不许削成尖下巴 / 瘦长脸 / 菱形脸 / 长中庭（写实感的主要来源），也不许圆成一颗球（Q 版）。**照片本人偏瘦偏长的，一律改成这样。**
- **五官必须同步「缩小一档、简化一层」**（脸压短、眼放大之后，剩下这几处不变小，脸就显挤、显老——这是「满意样张」和「写实样张」之间最容易被忽略的一处差别）：**鼻子**缩小 15~20%、**鼻子要短**（鼻底位置偏上，鼻子只占脸高的一小段），只有一个小圆鼻头 + 两侧各一条浅弧，**鼻梁几乎不画、不勾鼻翼外轮廓、不画鼻孔**；**嘴缩小到嘴宽 ≈ 脸宽 1/4~1/4.5**（真人约 1/3），上唇薄、下唇略厚、唇峰清楚、唇线干净，**不画唇纹、不画口角纹**；**耳朵**缩小约 15%，上缘与眉毛齐平，正面几乎被头发挡掉一半；**眉毛**简化成一条**实心的深色弧带**——眉头略粗、眉尾渐细、边缘干净，**不画一根根毛流、不画杂毛、不画眉尾飞出去的细笔触**；**苹果肌做成两个明确的圆球面**，各带一片淡粉红晕（腮红不超过眼外角的垂线），这是「甜」的来源之一。
- **骨相只用明暗、不勾骨点**：颧骨、下颌角、眉骨、鼻骨、锁骨**都不勾轮廓线**，只靠明暗与转折表现；剪影是一条连续柔弧，脸上不出现硬折角、不出现凹陷的太阳穴。
- **年龄靠形体，不靠皱纹**：年龄感锁在 **58-66 岁**，但只由**发色、体态、气色、皮肤明暗结构**表达。**法令纹、眼袋、泪沟、鱼尾纹、抬头纹、眉间纹、颈纹、手背血管与指关节褶皱一律不画**——皮肤是**一整片干净的色块**，只有明暗与红晕，没有一条线状纹路。（皮克斯的成年与老年角色从来是用轮廓和色块演年龄，不是画皱纹。）气色好、面颊紧致度高，但仍**不画任何线状纹**。
- **手与耳廓也简化**（鼻子、嘴、眉已在上面那条写清，这里不重复）：手指修长但**指节不画、不画手背血管与褶皱**，指腹圆润，指甲简化成一个圆角小面；人中一小段浅凹；耳廓只有外圈 + 一条内弧。
- **细节密度（真实感来自细节多，动画感来自细节少但每处精致）**：皮肤不得有任何照片纹理（毛孔、绒毛、颗粒、色斑噪点），过渡像手绘渐变；头发成块成片、不画单根发丝；布料不做纤维扫描。
- **认人只靠这几样**：发际线形状、眉形与浓淡、眼型的走向、鼻头与唇的具体形状、耳形、肤色与红晕、体型胖瘦的整体感觉；另加 **两眼间距 ÷ 单眼宽、眼睛高度位置、中庭 ÷ 下庭** 这三个比值不变。
- 目标：**一眼认出是图 A 本人，但头身比、脸型、骨相、眼睛、皮肤、头发全部是动画片那一套**——像那种三维动画家庭短片里的爸爸妈妈（大眼睛、圆脸、发块有油亮光泽），不像一张精修证件照。
【三、眼睛（只此一段）】
- **这是全篇最重要的一条：眼睛必须明显大于真人，而且要「大到有点不真实」。** 以图 A 的眼睛为基准，眼裂**宽度 +35~40%、高度 +30~35%**（宽略多于高，保持**杏仁形偏圆**——内眼角留一个小尖、外眼角略上扬，整体接近圆但不要真画成正圆），硬上限 1.45 倍，只向脸外侧扩；**两眼间距与眼睛高度位置不变**，不许为了显年轻把眼往中间挤。判据：**单只眼睛的宽度约等于脸宽的 1/3（不得小于 1/3.4）、高度约等于脸宽的 1/4.2**——**这个尺寸放到真人脸上是夸张的、甚至有点过头，那才是对的；如果你看着觉得「挺自然」，就是没做到。** 眼裂上下要开够，**上眼睑只轻轻压住虹膜上缘**，不许把眼睛压成细缝、不许上眼睑盖住半个虹膜。**眼睛一旦回到真人大小，整张脸就回到真人；眼睛一小，脸就立刻显长。**
- 虹膜要**大到接近填满**——直径约为眼裂高度的 **100%**，**与上下眼睑上下相接**（最多只留一条发丝细的缝）；眼白只剩**左右两侧各约 1/10 眼裂宽**的窄条，加内眼角一小块楔形眼白。**判据：眯起眼看，眼睛是两颗几乎纯黑的圆，眼白像两道细边——不是两个大白眼球中间各嵌一个黑点。**两头都禁：**不许虹膜小、眼白四边都空**（会变呆、变写实、眼神散），也**不许把眼裂上下撑开到露出大片眼白**（会变圆眼、变 Q 版）；两只虹膜在各自眼裂里的位置一致对称、都在正中偏外 5~10%，「虹膜外缘到眼裂外缘」距离左右相等，任何一只都不许贴内眼角。
- 双眼平视镜头、视线平行；头部 3/4 转动或微侧头时眼球回转看镜头，不许顺头看出去。
- 材质：虹膜深棕→琥珀、带放射纤维纹；角膜上盖一层**厚而边缘清晰**的水光层；一对**干净的白色圆点高光**（一大一小、边缘略柔）左右对称——像动画角色那样明确的两点，不是细碎的反光；上眼睑有厚度并在眼白投淡影；**睫毛明显可见——上睫毛 5~7 簇、略向上翘，眼尾两三簇略长**。
- 禁止内斜 / 外斜 / 对眼、虹膜死黑、玻璃珠、眼神呆滞。

【四、光与皮肤】
- **光源几何**：**柔和高调光**——主光是**画面左前上方约 35~40° 打下来的一大片柔光**（像一扇大窗），整体明亮、通透、暖；人物的受光面均匀饱满，脸的两侧只留**薄薄一层柔和的暗面**做出体积，不做明暗对半的硬分界；肩线与发块外轮廓上轻轻勾一道柔光边。**判据（三条一起看）：① 脸上最亮处与最暗处的亮度差只有 0.3~0.8 档，过渡非常柔（**认可的那版成人图几乎是平光，宁可更平、不要更立体**）；② 下巴正下方只有一层很淡的柔和阴影，不是一块硬的黑投影；③ 整张脸被压暗一半、或出现明显的一侧深一侧亮，就是打光太硬——那是电影侧逆光，不是这套图要的「甜」。**
- **明暗结构**：**以柔和的体积过渡为主**——靠鼻梁、脸颊、下颌那些圆润起伏做出立体感，不靠硬明暗切分；亮部干净不死白，暗部通透偏暖不发灰。**判据：眯眼看能看出脸的圆润起伏（鼻子、苹果肌、下巴的圆），但看不出「一半亮一半暗」的那条分界。**
- **皮肤高光（要润、不要一点点扎眼的白）**：额头一片大柔光；鼻梁一条竖向柔光；鼻尖一个**很小很柔**的亮点（边缘化开，不要锐利小白点）；颧骨一片柔和亮面；上下唇各一点温润亮光；内眼角一点水光。**高光是成片的柔光，不是一颗颗硬点**——但要「润」，绝不是哑光。
- **肤色**：**暖白偏象牙**，脸颊有淡淡红晕，淡妆、唇色柔和偏珊瑚；**皮肤是一整片干净色块，没有一条线状纹路**；不要冷调。
- **色调**：**暖调、低饱和的粉嫩通透**——整体高明度、干净柔和，暗部带暖不发灰；**不要浓艳、不要高饱和、不要糖水锐色**，饱和度向图 C 那张宝宝图看齐。

【五、头发】
- 发型发量按图 A：齐肩微卷发，**发片成块、有几处大弧度的卷**，发量与走向以照片为准。
- **头发不许「夹脸」——这条比蓬不蓬更重要**：头发顺着头骨轮廓梳理（中分 / 侧分 / 齐耳都按照片来），**在脸颊两侧与脸的外轮廓之间留出空隙**——不要把头发压到脸颊上、不要让两缕头发贴着内脸颊垂下来，那等于给脸加了一副竖框，脸再短也会被看成长的；长发自然垂在肩前、发尾带一点向外的柔弧；**发根要立起来、头顶不许塌**，但**不要为了显脸小去做额外的蓬松外扩**（顺直贴头完全可以；发型本身带卷度就按照片）。外轮廓是饱满的弧，不是两条紧贴脸颊的直线。
- **发色锁**：照片什么色就是什么色，**不许整体漂浅成棕 / 栗 / 黄褐**；颜色以照片为准，少量灰白可保留；逆光**只在发块的整圈外轮廓**形成一道明亮边缘光，**发块内部不透光、不许背景亮光从发缝里穿过来**、不许整头呈现半透明。
- **发块，不是发丝（最容易被忽略的一条）**：头发是**成块成片**的——由若干**大发片**叠成，一片由十几根发丝**粘成一个整体**，**片与片之间是明显的深色缝隙，片内部实心、不透光**；发片外缘是**光滑的大弧线**，只在最外轮廓留 3~5 根**粗而短的挑发**；发块表面有一层**整体的油亮高光**（像打了发蜡），不是一根根发丝各自反光。发际线自然、鬓角与后颈干净。**禁止发丝一根根数得清、禁止束间透出背景光、禁止被风吹散的绒毛感、禁止真实的毛发质感、禁止假发套。灰白发同样成块成片。**

## 4. 生成顺序与一致性技巧

**推荐顺序**：`宝宝（现有成品，作母版）→ 爸爸 → 妈妈 → 爷爷 → 奶奶 → 外公 → 外婆`

- **宝宝那张定基调**：你已经有的这张成品就是整套的「风格母版」，版式、色调、字体、标签位置全以它为准，不用重出。
- **喂参考图**：宝宝那张传四张（**宝宝照片 / 已认可的成品设定图 / 服装图 / 口水巾图**）——其中成品设定图（图片生成 7 那张）是**脸型风格与画风的基准**，不能省；**六位成人传三张**——① 本人照片（定脸）② 服装图（定衣服）③ 宝宝设定图（定版式与画风）。顺序别乱，**人物照片一定放第一张**，模型默认第一张是人物主体来源；并在提示词开头加一句：
  > `第一张只取长相，第二张只取服装与鞋，第三张只取版式与画风；第三张里的人物长相和服装一律不要。`
- **版式图只用宝宝那一张**：七张共用同一个版式母版，模型才会给出同一套构图；若拿爸爸的成品当妈妈的版式图，妈妈那张的版式会跟着爸爸那张的误差走，越传越偏。
- **一次只改一个人**：不要指望一张图里塞两个人，AI 会串脸、串衣服。
- **表情卡单独补**：如果 4 张表情卡总是崩（大小不一、脸不像同一个人），就单独生成一张「4 格表情条」再后期拼进卡片框里——**卡片的圆角底与暖黄描边最好也用设计工具加**，比 AI 画得整齐。
- **重抽而不是改词**：同一提示词抽 3-4 张再挑，比反复改词更有效；只在**稳定跑偏**（比如一直显老、一直换衣服）时才改提示词。

## 5. 出图后检查清单

- [ ] **第一眼：这是动画角色还是真人照片？** 如果像实拍照片 = 失败，重抽或加强「三维动画渲染」描述。
- [ ] **光影四问（比"是不是动画"更准）**：① 光的方向对不对？**宝宝**要一侧脸暗一侧亮（明暗差 ≥1.5 档）；**成人**要柔和高调、只有薄薄暗面（明暗差 0.5~1 档），成人若被压暗半张脸 = 打光太硬。② 皮肤高光是**成片的润光**还是**一颗颗扎眼的白点**？③ 头发是**成块的发片 + 整层油亮高光**吗（不是一根根发丝发亮）？④ **背景比人物更白更亮**吗？
- [ ] **和设定图左侧大特写并排比**：把成品左图和设定图左图各截一半拼在一起，看皮肤的通透度和头发的高光是不是一个级别；差一档就补提示词，不要靠后期调。
- [ ] **缩到 20% 看**：还像婴儿照片吗？像就说明细节密度太高、动画感不够，补【造型语言】段重抽。
- [ ] **眼睛是"设计过的眼睛"吗**：虹膜比例对不对（**宝宝 90~~95%、成人 100% 填满**）、**眼白是否还留得住**、有内外两层、水光层够厚、高光点是否锐利？（四张表情卡里的小眼睛也要一起看）
- [ ] **下颌线还在吗**：脸有没有圆成一颗球、下巴完全消失？（丢了就回调下巴缩短幅度）
- [ ] **手是婴儿的手吗**：手指短粗肉感、指节不明显、手背有凹窝？还是画成了缩小版成人的手？
- [ ] **宝宝那张四重校验**：脸是图 A 的宝宝吗？衣服是图 C 那件吗？口水巾是图 D 那条吗？版式是图 B 那种吗？
- [ ] **成人那张双重校验**：脸是本人照片吗？衣服和鞋是服装图那套吗（不是照片里原本穿的）？
- [ ] **【成人专用】像动画片还是像精修证件照？** 五个判据，中一个就重跑：① **三视图里数得出约 5.5~6 个头高**（能数出 7.5 个 = 真人比例）；② **脸是「短圆」不是「竖蛋」**——把左侧大特写的脸剪影单独描出来，横着略扁才对；脸宽 ≈ 脸高 × 0.95~~1.0、下庭明显短、下巴极小（**脸一长就整张垮掉，这是第一顺位的检查项**）；③ **眼睛明显比真人大**——眼宽 ≈ 脸宽的 1/3、虹膜 100% 填满、眼白只剩左右两条细边（看着和真人差不多大 = 没做到）；④ **脸上一条线状纹都没有**（法令纹 / 眼袋 / 鱼尾纹 / 颈纹 / 手背血管，有一条就不对）；⑤ **五官小、眉眼简化**——鼻子小且短、嘴宽只有脸宽 1/4~~1/4.5、耳朵小、眉毛是一条实心弧带（没有一根根毛流）、苹果肌是两个圆球 + 淡腮红；⑥ **头发是成块的宽发片 + 整片油亮高光**，发根立起、**两侧没有紧贴内脸颊垂下的两缕**（顺直贴头没关系，夹脸不行）。
- [ ] **【成人专用】光有方向吗？** 下巴正下方有没有一块暗投影？整张脸亮度均匀、两侧一样亮，说明模型又用回了柔光箱正面光。
- [ ] **【成人专用】脸被削瘦了吗？** 下颌是不是从脸颊斜着收进去、成了上宽下窄？下巴是不是变尖变长？是就说明又滑回照片脸了——要的是「椭圆偏饱满、下颌一条干净大弧」。
- [ ] **版式校验（四卡版式）**：左侧大特写占 33~35% 且通高吗？**右上正好 4 张表情卡片、大小一致、顶端对齐吗？卡片下方中英两行标签齐吗？右下三视图是 3 张吗？** **有没有多画右侧细节栏、有没有多画左上角标题？** 和宝宝那张摆一起，三块分区能对齐吗？
- [ ] **脸对上图 B 了吗？** 拿图 A、图 B、成品三张并排：成品要**一眼认出是图 A 那位宝宝**，而**脸型轮廓、五官比例、画风都是图 B 那一套**（宽短肉、下半脸最宽、下巴宽圆而短）。不像 A = 跑偏；脸型不像 B = 又回到照片脸。
- [ ] **背面是正常后脑吗？** 头发自然覆盖、发丝顺头型向下，**没有多个发旋、没有旋涡状高光点**。
- [ ] **4 张表情卡是同一张脸吗？** 四张的脸型、发际线、痣、服装必须一致，只是表情不同；四张之间至少三处可见差异（不要四张都是微笑）。
- [ ] **发色还是本人那个颜色吗？** 头发主体有没有被整头染成棕色/栗色？逆光只应作用在**发块的整圈外轮廓**，不是从发缝里透出来。
- [ ] **眼睛有没有斗鸡眼？** 按顺序查三处：① **两只虹膜在各自眼裂里的相对位置是否一致**（是不是一只偏内、一只偏外）；② **有没有哪只眼的虹膜贴住了内眼角**；③ 两条视线是否平行、是否都在看镜头。三条里中一条就算失败。
- [ ] **两眼高光点是否左右对称？** 一只在左上、一只在右上，会立刻显得"眼神发散"。
- [ ] **衣服是「穿上去」还是「贴上去」**？肩线、领口、袖口有没有贴合身体？有没有悬浮、穿模、硬邦邦不贴身？
- [ ] 衣服图案在**八个画面**（大特写 1 + 表情卡 4 + 三视图 3）里有没有变形、重复、跑位？
- [ ] 三个视角是**同一个人**吗？（脸型、发际线、痣、酒窝是否一致）
- [ ] 三张全身图的**身高比例**一致吗？脚有没有被裁掉？
- [ ] 衣服图案、扣子数量、领型在三张里有没有变？
- [ ] 年龄感对不对？老人有没有被画成 80 岁，或反过来被磨成中年人？
- [ ] 手部：五根手指、关节方向、有没有多肢？
- [ ] 背景色与上一张是否完全一致（拼一起不打架）？
- [ ] 中文标签有没有错字乱码？（有就后期覆盖）

- 宝宝坐在妈妈腿间，被妈妈双手轻轻环在身前，手里捏着一只小布偶
- 爸爸盘腿坐在妈妈右侧，身体前倾靠过去，右手搭在妈妈肩后，左手轻碰宝宝的小手
- 三人视线都朝镜头、各自微笑，**不互看**——互看像抓拍，看镜头才像封面

**光线**

- 主光：左后方 45° 斜射窗光（侧逆光），穿过纱帘后变柔
- 补光：右侧墙面反射的漫射光，保证脸部不发暗
- 色温 4500-5000K，发丝与肩线有柔和轮廓光，地毯上有淡淡窗格光斑
- 明暗比收着点：脸部亮部不过曝，阴影里仍保留细节

```text
以我上传的三张角色设定图为唯一人物与服装依据（爸爸 / 妈妈 / 宝宝的设定图各一张），生成一张横向 16:9、1125×633 px 的高清主页背景图，**三维动画电影级渲染**（三维家庭动画那种卡通化 3D，**不是真实摄影、不是真人照片、不是 2D 插画**）。

【只取人物，不要搬版式】三张设定图都是多画面拼版对照图（大特写 + 4 张表情卡 + 三视图）。这里只提取其中的人物长相、发型、服装与身材比例，**不要复制它们的排版、卡片框、标签文字、表情小图与背景地毯**。输出画面里只有三位人物，每人只出现一次。

【人物与服装】三个人的脸型、五官、发型发色、肤色、年龄感、身材比例，与各自设定图完全一致，不要串脸、不要互换五官、不要美颜改变年龄感。服装严格沿用设定图中的那套，款式、颜色、图案、领口袖口一律不改，宝宝的连体衣与口水巾保持原样。设定图中的正面与侧面视图可用来辅助理解身形与服装的立体结构，但不要把三视图当成多个人物画进画面。

【场景】夏日午后四点的客厅，落地窗前。暖白色纱帘半掩，窗外只有柔和的亮面天光，不出现建筑、街道与天际线。地面铺浅豆绿针织绒毯，右上角入画一角米灰色布艺沙发，左侧一株龟背竹、右侧矮柜上一盏未点亮的暖光台灯，均做虚化处理。前景地毯绒毛与一只虚化的木质小玩具形成景深层次。画面干净有序，无杂物堆积。

【姿势与构图】妈妈盘腿坐在地毯上，重心居中偏左；宝宝坐在妈妈腿间、被妈妈双手轻轻环在身前，手里捏着一只小布偶；爸爸盘腿坐在妈妈右侧，身体向前倾靠过去，右手自然搭在妈妈肩后，左手轻碰宝宝的小手。三人的身体要有真实接触（环抱、搭肩、手碰手），不要并排悬空站立。三人都看向镜头，各自微笑，不要互相对视。三人整体位于画面**水平居中、垂直 30%-75% 的核心区**，头部集中在垂直 40%-58%，相互贴近但不遮挡面部；画面上下各留约 20% 空白（天花板与地毯），人物不贴上下边缘；左下角保持空旷，不放人物主体。

【光线与色调】左后方 45 度斜射的窗光为主光，穿过纱帘后变得分散柔和，在发丝与肩线勾出柔和轮廓光；右侧墙面反射的漫射光补亮面部；地毯上有淡淡的窗格光斑。色温 4500-5000K，整体暖白、奶油、浅木色调，沙发的一点雾霾蓝作冷色平衡。画面通透温暖，浅景深，背景轻微虚化。

【画质】**电影级三维动画渲染**，不是相机拍摄：皮肤有次表面散射与多层高光（鼻尖、颧骨、唇），无毛孔噪点但**不是哑光塑料**；毛发成束、发梢透亮、有柔和边缘光；地毯与布艺有绒感与织物质感；窗外天光略过曝，画面有空气感；整体像动画电影的官方家庭宣传图。

【禁止】不要文字、logo、水印、边框、分格线；不要真实照片质感、不要塑料感与手办感；不要 Q 版化（头身比低于 1:4.5）、不要眼睛放大超过 1.15 倍、不要改动两眼间距与眼睛高度位置、不要斗鸡眼或内斜视；不要多于三个人物、不要重复人物；不要出现表情小图与细节特写格；不要复制设定图的拼版版式；不要裁掉头顶；不要人物贴上下边缘或放在左下角；不要强对比硬阴影、不要冷色调；不要合成感、贴图感、抠图边；不要手部畸形、多手多脚、肢体穿插；不要串脸或人物重叠变形。
```

### 6.4 三人合体总串脸？先用这个更稳的做法

一张图里塞三张真实的脸，是所有 AI 生图里最容易翻车的场景，串脸、换衣服、手部畸形几乎必踩。要 100% 保真，走「**空场景 + 抠图合成**」：

1. 先让 AI **只生成场景**（上面 6.3 的提示词，删掉【人物与服装】和【姿势】段，改成「画面中不要出现任何人物」）；
2. 把已定稿的爸爸、妈妈、宝宝设定图里的大特写**抠出人像**；
3. 在设计工具里按上述姿势拼贴，注意三人**光源方向一致**（都从左侧来）、色温统一；
4. 用「投影 + 轻微调色」压住抠图边，人物脚下加软阴影落地。

代价是要动手拼，好处是脸和衣服永远是对的、想换姿势随时挪。**如果只出一次、要求不高，直接用 6.3 的提示词抽 5-6 张挑一张更省事。**

## 7. 后期排版建议

1. **统一出口**：七张出图后统一裁成 4:3、统一色调（可加同一层暖白调色），再拼版。
2. **文字层单独做**：中文标签统一用同一字体、字号、颜色（深棕 #5A4632），比 AI 直出整齐得多。
3. **拼版方案**：竖版长图（7 张纵向排列，适合手机看）/ 3×3 网格（含 1 张主页背景图居中，适合打印）。
4. **混排解法（七张已用同一套背景，一般不需要了）**：因为背景已经统一（米白墙 + 浅豆绿绒毯），拼版时通常直接对齐即可。若个别张出得偏色，用下面任一招压住——
   - **A 独立成页（最省事）**：宝宝那张当系列**封面**单独占一页，六位大人在后面同排。封面和内页背景不同完全正常，反而有层级。
   - **B 统一留白**：每张都裁成 4:3 后套同一个奶白色边框（留白 6-8%，色值取宝宝毛毯的浅米白 #F2EBE0），背景差异会被边框压住，视觉上自然归为一组。
   - **C 调色对齐**：把六张成人图的背景明度统一调到和宝宝毛毯一致，并统一加一层 +3 暖调，色调一致后背景内容差异就不显眼了。
   - **D 分隔块**：3×3 网格里，用纯色米白留白块穿插在宝宝与大人之间作呼吸位。

## 8. 换装提示词（人物已定稿，只换衣服）

> 适用场景：七张设定图都出好了，以后只想给某个人换一身衣服（换季、换新衣、换口水巾），**人、脸、姿势、版式、背景一律不动**。  
> 输入只需两张：**① 已完成的设定图（底图）② 新服装图**（有口水巾/鞋/配饰就再加对应图）。  
> 这套换装逻辑和 3.1–3.6 生成时**完全一致**——初次生成就是「照片定脸 + 服装图定衣服」，所以以后换季换新衣，走的还是同一套：换一张服装图就行，提示词一句都不用改。

### 8.1 通用换装提示词（直接复制）

```text
只替换服装，其余一切保持原样。

【底图】我上传的第一张是已完成的角色设定图。人物长相、姿势、版式、背景、光线、色调、**右上表情卡的位置与卡片样式、卡片下方的中英标签、四角涂鸦**，全部保持不变，不要重新设计、不要重新排版、不要改变任何构图比例。

【新服装】我上传的第二张是服装图（如另有口水巾/鞋/配饰图也一并参照）。严格还原其款式、版型、颜色、图案、领口袖口、纽扣、包边与面料纹理，不换色、不简化图案、不增删元素。

【必须同步替换的位置（缺一处就会穿帮）】
1）左侧大特写中露出的衣领、肩部与胸前；
2）三张全身图（正面 / 侧面 / 背面）的整套服装，背面要能看清后背版型与图案；
3）右上 4 张表情卡片里胸像露出的领口与肩部。
以上 **8 处人物形象**（大特写 1 + 表情卡 4 + 三视图 3），必须是同一件衣服，颜色、图案位置、褶皱走向完全一致。

【穿在身上的要求】按人物体型重新贴合：肩线落肩、领口贴颈、袖口包臂、下摆自然垂坠；布料随身体起伏有真实褶皱与阴影；图案按实际比例缩放，不变形、不错位、不重复。若服装图是平铺商品图，请理解结构后穿到身上，不要照搬硬挺的平铺轮廓。

【严格不变】脸、五官、发型发色、肤色、年龄感、身体比例、站/坐姿势、手部动作、背景与地面、光线方向与色温、文字与标签、整体色调。

【禁止】不要换脸、不要改发型、不要改姿势、不要换背景、不要改版式、不要增减画面元素、不要重绘文字、不要改变画面分格比例。
```

### 8.3 有局部重绘（蒙版 / inpainting）功能时，优先用它

整图重绘最大的风险是**脸被改掉**。只要能框选区域，就走这条路：

```text
只在我框选的区域内重绘服装，蒙版以外的一切像素保持不变（脸、发型、身体轮廓、背景、文字、分格线）。
框选区内按上传的服装图生成这件衣服，保持原有姿势、身体边缘与光影方向一致，布料自然贴合身体。
```

操作顺序：先框三张全身图的衣服区域 → 再框左侧大特写的领口与肩部 → 最后逐个框右上 4 张表情卡片里的领口。**表情卡最容易漏，别忘。**

### 8.4 换装后逐项核对

- [ ] 8 处人物形象是**同一件衣服**吗？（大特写 1 + 表情卡 4 + 三视图 3）
- [ ] 背面那张的后背图案对不对？（最容易凭空编一个后背）
- [ ] 4 张表情卡片里的领口/口水巾换成新衣服了吗？（**最常忘的一步**）
- [ ] 脸还是原来那张脸吗？（整图重绘最常见的翻车点）
- [ ] 卡片框、中英标签、涂鸦有没有被一起重画？
- [ ] 新旧两版并排看，人物轮廓位置有没有轻微位移？（位移了就不能和另外六张对齐拼版）

### 8.5 一点经验

- **换装比初次生成难**：初次只要对一次，换装要同时对 8 个位置。所以优先用局部重绘，别指望一句提示词整图搞定。
- **一次只换一个人、只换一处**：想同时给宝宝换衣又换口水巾，分两次做，第二次拿第一次的成品当底图。
- **换完存新版，别覆盖旧版**：文件名带上衣服标识（如 `宝宝_蓝裙.png` / `宝宝_红裙.png`），以后要回滚或做对比都方便。

## 9. 整体返工清单（拿成品当底图，只修 N 处）

> 用在「版式、服装、三视图都对了，只剩材质/光/小手/眼睛」的阶段。核心原则：**其余全部锁死，一次只修 3-4 处**，改的项越多越容易顾此失彼。

### 9.1 完整重跑版（照底图改 4 处）

```text
以我上传的这张图为基础，其余全部保持不变，只修下面四处。**版式一律照原图**：左侧通高大特写、右上 4 张表情卡片（位置、大小、圆角浅底、暖黄描边、卡片下方中英两行标签）、右下三视图，以及服装与口水巾、背景色调、涂鸦位置，全都不要重排、不要重新构图，**不要加回右侧细节栏、不要加回左上角标题**。

1）手：改成肉感的婴儿手。手指短粗、指节不明显、指腹圆润、手背有小凹窝；**每根手指之间要有清晰的分缝线，手指各自独立圆润，不要糊成一整块像连指手套**；皮肤干净，不要褐色小斑点、雀斑或颗粒。不要画成缩小版成人的手。

2）头发：**保持成块成片的发片结构**——一片由十几根发丝粘成一个整体、片与片之间是明显的深色缝隙、片内部实心不透光，外缘是光滑的大弧线、只留几根粗而短的挑发，表面一层整体的油亮高光。**发色必须与原照片一致（黑胎发就保持深黑到深褐）**，逆光只让发片的整圈外轮廓发亮，**不要整头变成棕色、栗色或黄褐色**；不要改回一根根细丝、不要刺猬头、不要露头皮。

3）背景：上半米白墙面与纱帘、地面浅豆绿针织绒毯的远端，亮度比人物高 1.5~2 档、高光溢出、接近纯白；人物是画面里最「实」的一块。背景与人物同亮就不对。

4）眼睛视线：双眼直视镜头，两条视线严格平行；头虽然有转动，眼球要回转看镜头，不要顺着头的方向看出去。两只虹膜在各自眼裂里的相对位置必须一致且对称，都落在正中偏外 5~10%——近侧眼与远侧眼的「虹膜外缘到眼裂外缘」距离要几乎相等，任何一只都不许贴住内眼角。两只眼的高光点位置左右对称。两眼间距保持原样，不要往中间靠。

其余的脸型、五官大小、下颌线、发型发量、服装、表情、姿势、标签文字、涂鸦，全部照原图。
```

> ⚠️ 铁律：**改动清单里没点名的位置，模型会照抄底图**。所以要改的东西必须逐条点名。  
> 反过来的坑同样存在：**别在新话术里提「细节栏 / 第 2 格」这类旧版的词**——一提，模型就会给你画回一竖排细节格。旧版遗留的返工话术已经全部作废。

### 9.2 只修眼睛（最省时的一次实验）

```text
只改眼睛的视线，其他一切像素保持不变。

两只虹膜在各自眼裂里的相对位置改成一致且对称：都以各自眼裂为基准，落在正中偏外 5~10%，内侧白露出一小条、外侧白略多。任何一只眼的虹膜都不许贴住内眼角。双眼直视镜头，两条视线严格平行，不要看向画面一侧。两只眼的高光点位置左右对称。两眼间距不要动。

眼睛大小、虹膜大小、眼白比例、脸型、表情、版式、服装、背景、光线、文字，全部保持原样。
```

### 9.3 局部重绘（最稳，推荐）

只框住右下那张背面图（或任意一张表情卡），其余画面一律不碰。

```text
只改我框选的这一张，其他所有画面、版式、文字、服装、光线一律不动。

背面画正常的后脑勺：头发自然覆盖整个后脑，发丝从头顶顺着头型向下垂，发束分层、有蓬松感与发梢细节。**不要交代发旋**——不要刻意露出发旋、不要画成旋涡或旋涡状高光点、不要出现放射状分缝或分缝线。

发量、发色、发长、发质与正面图和侧面图完全一致；身高、坐姿、头身比与另两张一致，仍是同一个宝宝在原地转身。
```

### 9.4 只改某一张表情卡（最省时的单项修）

某一张卡片的表情不对（比如 Curious 画成了普通微笑、Surprised 和 Happy 太像），只重画那一张。

```text
只改右上 4 张表情卡片里从**左数第 N 张**，其他三张卡片、左侧大特写、右下三视图、所有文字与涂鸦一律不动。

这一张的表情改成 **【要改成的那种】**（自然＝嘴角平、眼睛不笑；开心＝张嘴笑、眼角弯成月牙；惊讶＝嘴成 O 形、眉毛抬高、眼睛睁大；好奇＝闭嘴、头略偏、两眉一高一低、双唇微收、目光斜向上）。

保持：卡片的大小与圆角位置不变、卡片里的取景范围不变（从头顶到胸口）、人物角度不变（正面）、服装与口水巾不变、脸型五官与其余三张完全一致；卡片下方的中英标签保持不变。
```

### 9.5 顺序建议

1. **先做单项局部改**（9.2 眼睛 / 9.4 某张表情卡 / 9.3 背面）——成功率最高，改完版式不受影响。
2. **再整图重跑**（9.1）——把剩下的手、头发、背景、视线一起改；此时单项已无遗留，不会互相拖累。
3. 若是从头新做、底图没有旧坑，直接走 9.1 的四处即可。
4. 每次改完**另存新文件**，别覆盖旧版，方便回滚和对比。

### 9.6 合并版：表情卡 + 三处小瑕疵（一次跑完）

> 用在「版式、光影、动画感都对，只剩某张表情卡 + 手指 + 发色 + 眼睛对齐」的阶段。四处一起改，仍然属于局部修补，不动版式。

### 9.7 脸太长 / 眼睛不够大（成人专用，2026-11-07 新增）

> **用在**：整张图版式、画风、光都对，就是**脸看着偏长、不够「短圆」**，**眼睛还不够那种「动画大眼」**。这是成人版最高频、也最难靠形容词一次写准的两个偏差。  
> **原因不只在脸上**：脸长的观感有三个来源，只改其中一个不够——① 脸宽长比偏小（0.85 会明显显长，要压到 0.95~1.0）；② 下庭（鼻底到下巴）没压缩，下巴被拉长；③ **头发贴着脸颊两侧往下挂**，等于给脸加了一副竖框，脸再短也被看成长的。（注意：**是「夹脸」而不是「不够蓬」**——认可的妈妈图 2 是顺直中分贴头，照样很对，关键在头发与脸颊之间留没留空。）

**第一步：先查是不是头发在捣乱。** 把成图和新提示词比一眼——**如果两侧头发是顺贴脸颊垂下来的直线**，那就是第 ③ 条，这条不改，脸怎么调都显长。

**第二步：整图重跑，把下面这段贴在提示词最后**（会覆盖前文的比例句，不会打架）：

```text
【覆盖补丁：脸压短、眼放大、发蓬起——以下三条优先于前文所有比例描述】

1）脸必须比前文写的更短更圆：脸宽 ≈ 脸高（发际线到下巴）的 1.0 倍，即接近正圆；下庭压缩——鼻底到下巴的高度只有眉头到鼻底的 0.75 倍；下巴极小极短，只是一个圆润的收口，不向下垂、不拉尖；最宽点在颧骨到脸颊那一带，脸颊体积比照片鼓 25~30%。判据：把脸的剪影单独描出来，是一个横着略扁的短蛋，不是竖着的长蛋。不要尖下巴、不要长中庭、不要瓜子脸、不要椭圆脸。

2）眼睛再大一档：单只眼睛宽度 ≈ 脸宽的 1/3、高度 ≈ 脸宽的 1/4.2；虹膜直径 = 眼裂高度的 100%，与上下眼睑上下相接，眼白只剩左右两侧各约 1/10 眼裂宽的细边；眼型是杏仁形偏圆，内眼角保留一个小尖、外眼角略上扬。这个尺寸放在真人脸上应当显得夸张、甚至有点过头——如果看着「挺自然」，就是没做到。

3）头发不许夹脸（比蓬不蓬更重要）：头发顺着头骨轮廓梳理，在脸颊两侧与脸的外轮廓之间留出空隙——不要把头发压到脸颊上、不要让两缕头发贴着内脸颊垂下来；发根立起来、头顶不塌，但不要求蓬松外扩（顺直贴头也完全可以）。发片是宽条状、整片油亮，不画一根根细丝。

其余（版式、四张表情卡、三视图、服装、表情、背景、光线、色调、涂鸦）全部照原图不要动。
```

**第三步：还不够就用图 D 压。** 文字只能把脸拉回「短圆」这一档，要继续贴近你认可的那几张示例图，**必须上一张风格锚点**——把 4 张示例图里最接近的那张（或已经跑满意的那一版）当**图 D** 一起传，并在最前面加一句：

```text
图 4 只定动画化程度与脸部比例：脸型的短圆程度、下庭的压缩幅度、眼睛占脸的大小、头发的体积与块感，**以图 4 为准，优先于文字描述**；长相（发际线、眉形、眼型走向、鼻唇形状、耳形、肤色）仍以图 1 为准。
```

> **一句话记住**：脸短靠三个数（脸宽/脸高 0.95~1.0、下庭 0.75、下巴极小），眼大靠两个数（眼宽 1/3 脸宽、虹膜 100%），发蓬靠一个动作（头顶加高、两侧外扩）。**发不夹脸靠一个动作（脸颊两侧留空、发根立起）。这三项同改才见效，单改一项会被另外两项吃掉；配上「妈妈图 2」当图 D，基本能一次到位。**
